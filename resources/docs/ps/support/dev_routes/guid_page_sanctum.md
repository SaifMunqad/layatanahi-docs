# د Sanctum تصدیق او توکن معاینه

د '/test-sanctum-chat' او '/api/system/support/test-sanctum' لارې د Laravel Sanctum تصدیق او د سیشن کوکیز ارزوي. دا وسیله د کاروونکي پیژندنه، ایمیل، نوم او د Bearer توکن نښه ښیي.

پراختیا کونکي دا لارې د API توکنونو د ستونزو حلولو، د هیډرونو د سم والي او په Octane سرور کې د سیشنونو د دوام د تایید لپاره کاروي.
