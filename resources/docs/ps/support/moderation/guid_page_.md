# د ملاتړ ډلې رولونه او واکونه

دا انټرفیس مدیرانو ته اجازه ورکوي چې باوري کاروونکو ته د ملاتړ ډشبورډ او پراختیایي لارو د لاسرسي واک ورکړي.

دا ډاډ رامنځته کوي چې یوازې باوري مسؤلین مهمو تشخیصی وسایلو او معلوماتو ته لاسرسی ولري.
