# بنرهای تبلیغاتی و تصاویر صفحات ورود

مدیریت اسلایدهای تبلیغاتی ('/system/support/ads') و تصاویر احراز هویت ('/system/support/auth-images') کنترل کامل رسانه‌های بصری صفحه اصلی و صفحات ورود را مهیا می‌سازد.

می‌توان اسلایدها را بارگذاری، زمان‌بندی و لینک‌های هدف هر کمپین را تعیین نمود.
