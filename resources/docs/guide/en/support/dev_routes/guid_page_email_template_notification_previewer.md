# Email Template & Notification Previewer

The '/system/support/mail-preview' route renders a live transactional email template built with Laravel's 'MailMessage' class directly inside the browser.

This utility enables developers and designers to preview typography, call-to-action buttons, responsive layouts across mobile and desktop viewports, and localization strings without having to trigger outbound SMTP mail delivery.
