# Analog Canvas Clock Diagnostic

The '/system/support/clock' diagnostic screen showcases a high-performance minimalist HTML5 canvas sweeping clock component.

It is used to verify browser animation frame performance ('requestAnimationFrame'), theme color synchronization (light and dark mode transitions), and client-side rendering stability under high load.
