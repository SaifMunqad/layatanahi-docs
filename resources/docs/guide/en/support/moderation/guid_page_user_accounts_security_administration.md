# User Accounts & Security Administration

The User Accounts Manager provides system administrators with tools to search, moderate, and secure all registered customer and merchant user accounts.

Features include soft-deleting malicious or compromised accounts, restoring deleted profiles, disabling two-factor authentication (2FA) locks in recovery scenarios, and generating secure password reset links with alternate email delivery.
