# Global Product & Variant Catalog

The Global Products manager ('/system/support/products') and Variant manager ('/system/support/products/variants/add') provide centralized governance over the master product taxonomy.

Administrators can define base products, manage multi-lingual title and description translations, curate variant attributes (sizes, colors, specs), and enforce catalog quality standards across the marketplace.
