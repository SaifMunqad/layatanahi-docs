# Brands, Units, Attributes & Tax Categories

This collection of catalog utilities includes Brands ('/system/support/brands'), Measurement Units ('/system/support/units'), Variant Attributes ('/system/support/attributes'), and Tax Categories ('/system/support/tax-categories').

Administrators can configure global brand registrations with logos, standardized SI measurement units and conversions, reusable variant attribute rules, and regional tax bracket assignments.
