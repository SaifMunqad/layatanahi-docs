# Categories & Subcategories Manager

The Categories and Subcategories management modules allow support teams to organize the multi-level product classification hierarchy.

The system includes an integrated Unsplash image search ('/system/support/subcategories/images/search') enabling administrators to search and apply high-resolution category banner artwork seamlessly.
