# Promotional Ads & Authentication Media

The Ad Slide Manager ('/system/support/ads') and Auth Image Manager ('/system/support/auth-images') provide complete control over visual assets shown on customer landing banners and authentication screens.

Staff can upload banner graphics, set target links and campaign schedules, and configure rotation parameters to highlight featured promotions and maintain a polished brand presentation.
