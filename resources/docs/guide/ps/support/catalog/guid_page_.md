# تبلیغاتي سلیډرونه او د پاڼو انځورونه

د اعلاناتو د سلیډر مدیریت ('/system/support/ads') او د ننوتلو د پاڼو انځورونه ('/system/support/auth-images') د لومړۍ پاڼې پر اعلاناتو بشپړ کنټرول ورکوي.

تاسو کولی شئ سلیډونه پورته کړئ، د کمپاین وخت او هدفمند لینکونه وټاکئ.
