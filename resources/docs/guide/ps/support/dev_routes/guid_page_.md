# د کینواس انالوګ ساعت ازموینه

د '/system/support/clock' پاڼه د HTML5 کینواس پر بنسټ انالوګ ساعت نندارې ته وړاندې کوي.

دا پاڼه د انیمیشنونو د سرعت، د روښانه او تیاره حالت د بدلون او د کاروونکي انٹرفیس د ثبات د ارزونې لپاره کارول کېږي.
