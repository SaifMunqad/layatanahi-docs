# د امنیتي هیډرونو او CSRF توکن معاینه

د '/api/system/support/test/debug-auth' او '/api/system/support/test/csrf' لارې د هیډرونو، کوکیز، X-XSRF-TOKEN او X-CSRF-TOKEN بشپړ معلومات او فعال سیشن ای ډي ښیي.

دا تشخیصی وسایل د AJAX او بهرنیو غوښتنو د امنیتي خنډونو په حلولو کې مهم رول لوبوي.
