# بررسی احراز هویت و توکن Sanctum

نقاط پایانی '/test-sanctum-chat' و '/api/system/support/test-sanctum' وضعیت احراز هویت Laravel Sanctum و کوکی‌های نشست را بررسی می‌کنند. این ابزار شناسه کاربر، ایمیل، نام و پیشوند توکن Bearer را برمی‌گرداند.

توسعه‌دهندگان از این مسیرها برای عیب‌یابی توکن‌های API، اطمینان از صحت هدرها و بررسی پایداری نشست‌ها در پردازش‌های Octane استفاده می‌کنند.
