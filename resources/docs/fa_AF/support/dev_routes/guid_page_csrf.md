# بررسی هدرهای امنیتی و توکن CSRF

مسیرهای '/api/system/support/test/debug-auth' و '/api/system/support/test/csrf' وضعیت کامل هدرها، کوکی‌ها، توکن‌های X-XSRF-TOKEN و X-CSRF-TOKEN و شناسه نشست فعال را نمایش می‌دهند.

این مسیرها ابزاری اساسی برای رفع خطاهای امنیتی درخواست‌های ناهمگام (AJAX) و درخواست‌های خارج از دامنه به شمار می‌روند.
