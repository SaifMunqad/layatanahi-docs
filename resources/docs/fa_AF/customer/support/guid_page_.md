# شرایط استفاده و حریم خصوصی

این پلتفرم بر اساس مقررات شفاف حفظ حقوق مصرف‌کنندگان و استاندارد‌های امنیتی معاملات تجاری فعالیت می‌کند تا اطلاعات خریداران و شفافیت مالی تضمین شود.

تمامی داده‌های شخصی، آدرس‌های ارسال و گزارش‌های تراکنش‌ها با پروتکل‌های رمزنگاری سرتاسری و استانداردهای جهانی تجارت الکترونیک محافظت می‌شوند.
