# گزارش‌ها

گزارش‌ها معاملات شعبه را به صورت‌های مالی تبدیل می‌کنند. داشبورد یک نمای کلی دوره در فروش‌ها،
خریدها، پرداخت‌ها، مصارف، مطالبات دریافتنی و مطالبات پرداختنی می‌دهد، و هر رقم به یک فهرست تفصیلی
پیوند دارد که می‌توانید چاپ یا تطبیق کنید.

گزارش‌ها فقط‌خواندنی‌اند. هرگز سندی را تغییر نمی‌دهند، پس باز کردن آن‌ها در جریان یک حسابرسی بی‌خطر
است.

## این صفحه درباره چیست

- مقایسه فروش‌ها، خریدها و مصارف در یک دوره.
- دیدن مطالبات دریافتنی و پرداختنی در یک نگاه.
- محاسبه مفاد خالص برای یک روز، هفته، ماه، سال یا کل تاریخچه.
- رفتن به فاکتورها یا پرداخت‌های پشت هر مجموع.

## ساختار صفحه

| بخش | چه چیزی نشان می‌دهد |
| --- | --- |
| فیلترها | انتخاب‌گرهای خط زمانی و ارز |
| مجموع‌ها | فروش‌ها، دریافت‌ها، خریدها، پرداخت‌های عواید، پرداخت‌های صادره، مصارف، مطالبات دریافتنی، مطالبات پرداختنی، مفاد خالص |
| اوسط‌ها | ارزش‌های اوسط و شمار سفارش‌ها برای دوره |
| خط زمانی | یک سطر برای هر دوره با همه ارقام |
| فهرست‌های اخیر | آخرین فاکتورها، پرداخت‌ها، مطالبات دریافتنی و پرداختنی |

هر مجموع یک پیوند به صفحه تفصیلی خودش است و خط زمانی، ارز و دوره کنونی را با خود می‌برد.

## خط‌های زمانی

| خط زمانی | دوره‌ها |
| --- | --- |
| روز | بیست‌وچهار سطل ساعتی |
| هفته | هفت سطل روزانه (پیش‌فرض) |
| ماه | چهار سطل هفته‌وار |
| سال | دوازده سطل ماهانه |
| تمام مدت | یک سطل برای هر سال تقویمی |

برچسب دوره نشان می‌دهد کدام سطل را می‌بینید، برای مثال «امروز»، «دیروز» یا «3 روز قبل».

## صفحه‌های تفصیلی

| گزارش | ستون‌ها |
| --- | --- |
| فروش‌ها | فاکتور، مشتری، سازمان، مجموع، پرداخت‌شده، باقی‌مانده، تاریخ |
| دریافت‌ها | فاکتور، مجموع، پرداخت‌شده، باقی‌مانده، تاریخ |
| خریدها | فاکتور، تأمین‌کننده، مجموع، پرداخت‌شده، باقی‌مانده، تاریخ |
| پرداخت‌های عواید | دسته، حساب بدهکار، حساب بستانکار، مبلغ، تاریخ |
| پرداخت‌های صادره | دسته، حساب بدهکار، حساب بستانکار، مبلغ، تاریخ |
| مصارف | دسته، یادداشت‌ها، ثبت‌شده توسط، مبلغ، تاریخ |
| مفاد خالص | نوع ورودی، مرجع، جزئیات، مبلغ، تاریخ |
| مطالبات دریافتنی | فاکتور، مشتری، سازمان، مجموع، پرداخت‌شده، باقی‌مانده، تاریخ |
| مطالبات پرداختنی | فاکتور، تأمین‌کننده، مجموع، پرداخت‌شده، باقی‌مانده، تاریخ |

هر صفحه تفصیلی پانزده سطر را صفحه‌بندی می‌کند و با اسکرول سطرهای بیشتر بار می‌کند. تغییر ارز خط
زمانی و دوره را نگه می‌دارد.

## نحوه استفاده

1. **فروشگاه > گزارش‌ها** را باز کنید.
2. خط زمانی و ارز را انتخاب کنید.
3. نخست جدول مجموع‌ها را بخوانید؛ شکل دوره را نشان می‌دهد.
4. روی یک مجموع کلیک کنید تا فهرست تفصیلی آن باز شود.
5. از انتخابگر ارز در صفحه تفصیلی برای مقایسه همان دوره به ارز دیگر استفاده کنید.
6. وقتی نسخه کاغذی لازم است، صفحه تفصیلی را چاپ کنید.

## چه چیزی محدود است

- خواندن به خواندن `store.reports` نیاز دارد. بارگذاری یا صادر کردن سپریت شیت‌ها به نوشتن نیاز دارد.
- همه ارقام محدود به شعبه‌اند: فاکتورهای صادرشده یا دریافت‌شده توسط شعبه، و پرداخت‌های حساب‌های
  شعبه. فعالیت شعبه دیگر کنار گذاشته می‌شود.
- شمار مشتریان جدید، هرجا نشان داده شود، در سطح کل کسب‌وکار است نه مخصوص یک شعبه.
- نتیجه‌ها به‌خاطر کارایی مدتی کوتاه ذخیره می‌شوند. سندی که چند لحظه پیش ایجاد شده ممکن است کمی
  دیرتر ظاهر شود.
- مطالبات دریافتنی و پرداختنی انتخاب‌گر خط زمانی ندارند؛ موقعیت کنونی باقی‌مانده را نشان می‌دهند.
- گزارش‌ها هرگز هزینه یا حاشیه هر سطر را فراتر از آنچه نمای مفاد خالص از اسناد می‌گیرد آشکار
  نمی‌کنند.

## نکات و رفع مشکلات

- **یک مجموع کهنه به نظر می‌رسد.** نتیجه‌ها برای مدتی کوتاه ذخیره می‌شوند. یک دقیقه صبر کنید و
  دوباره بار کنید.
- **برچسب دوره غیرمنتظره است.** خط زمانی سطل‌ها را تعیین می‌کند؛ خط زمانی هفته از هفته جاری آغاز
  می‌شود، نه از یک تاریخ دلبخواه.
- **مجموع‌های ارزی با حساب تفاوت دارند.** گزارش‌ها با نرخ‌های تبادل ذخیره‌شده به ارز انتخاب‌شده
  تبدیل می‌شوند؛ دفتر حساب مبلغ‌های اصلی را نشان می‌دهد.
- **مفاد خالص منفی است.** خریدها و مصارف در آن سطل از فروش‌ها و عواید پیشی گرفته‌اند. پیش از
  نتیجه‌گیری که داده غلط است، فهرست تفصیلی را باز کنید.
