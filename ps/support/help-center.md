# مرستې مرکز

**مرستې مرکز** ستاسو د پیل ټکی دی کله چې کومه ستونزه لرې. فرقي نه کوي چې *پیرود* کوې، خپل *حساب* مديرا کوې، یا د *سوداګرۍ* برخه کې کار کوې — دا دروازه ژر سم لارښود ته رسوي.

## له کومه پیل کړم

| غواړم… | ولاړ شه |
| --- | --- |
| زده کړم څنګه وپیریم او تسویه وکړم | [د کاروونکې کتنه](/docs/user/overview) |
| د غورلړدې یا بل مرسته | [پیرود](/docs/user/purchase) |
| خپل حساب او امنیت مديرا کړم | [پروفایل او ترتیبات](/docs/user/profile) |
| له AI وغواړم توکی ومومم | [AI مرستیال](/docs/user/ai) |
| د سوداګرۍ چارې مديرا کړم | [د سوداګرۍ کتنه](/docs/business/overview) |
| یوه عامه پوښتنه وپلټم | [د پوهې بانک](/docs/support/knowledge-base) |
| له یوه انسان سره خبرې وکړم | [له ډلې سره اړیکه](/docs/support/contact-team) |

## ډېرې کارول شوې چارې

- **د غورلړدې حالت** — زما بسته چېرې ده؟ → [پیرود](/docs/user/purchase) وګوره.
- **بېرته ورکړه او بېرته پیسې** — څنګه یو شی بېرته واستوم؟ → [د بېرته ورکړې تګلاره](/docs/legal/return-policy) وګوره.
- **ننوتل او پټ‌نوم** — نشم ننوتی → [پروفایل او ترتیبات](/docs/user/profile) وګوره.
- **ورکړې (تادیات)** — یوه charge ناسمه ښکاري → د **غورلړدې مرجع** سره له ملاتړ سره اړیکه ونیسه.

## لا هم مرسته مهل که؟

> **سپارښتنه:** مخکې له اړیکې، خپل **د غورلړدې مرجع** او د ستونزې لنډ تشریح چمتو وساته — ډلې ته ژرې مرستې لپاره ډېره مرسته کوي.

که پورته لارښود ستونزه حل نه کړه، [له ډلې سره اړیکه ونیسه](/docs/support/contact-team) او موږ به د **یکشنبه تر پنجشنبه، ۸:۰۰–۱۶:۰۰ (د افغانستان وخت)** ځواب درکړو.
