# پېژندنه

لياتناهی د یوه هدف پر شاوخنا جوړ شوی: **افغاني سوداګرۍ سره نښلول** او هرې سوداګرۍ ته هغه وسیلې ورکول چې د کار مديرا کولو ته یې اړتیا ده — له *پیرود* او *پلور* څخه تر *ګدام*، *مالیې* او *معاشونو* پورې.

## ستونزه

په دودیز ډول، سوداګرۍ معلومات په کاغذ شریکوي. عرضه‌کوونکی بل لیږي، پیرودونکی یې په ټیلیفون یا ډاک څېړي، او تادیې په اکسل‌شېټونو کې ثبتېږي چې له نېټې پاتې کېږي. اړیکې د سوداګریو ترمنځ *ورو*، *لاسي* او *باور‌نه‌لرونکې* دي.

نړیوال حسابداري سافټویر دې برخه حلوي، خو د یوه کوچني محلي دوکان لپاره اکثره **دروند او ډېر ګران** وي.

## د لياتناهی طریقه

لياتناهی دا لاسي دوره په آنلاین سیسټم بدلوي چې پکې پیرود، بل، د تادیې غوښتنه او تصدیق ټول **په یوه پلیټ‌فارم** کې منځته راځي:

- یوه سوداګري **پیرود** ثبتوي او د عرضه‌کوونکي بل ډیجیټل ترلاسه کوي.
- بل اړخ غوښتنه ګوري او تصدیقوي.
- **تادیې** او رسیدونه اتومات ثبتېږي، د هر ګام تاریخچې سره.

دا هره سوداګري — عرضه‌کوونکی، دوکان او پیرودونکی — **وصل او هم‌عقده** ساتي.

## دننه څه شته

پلیټ‌فارم د یوې سوداګرۍ شاوخوا ورځنیو چارو ترتیب شوی:

| ماډیول | څه مديرا کوي |
| --- | --- |
| **پیرودنې** | ننوتل اجناس، د عرضه‌کوونکي بل، راپورونه |
| **پلورنې** | پلور د محصول، بیې، اندازې او پیرودونکي پر بنسټ |
| **لګښتونه** | کرایه، سامانونه، معاشونه او نور لګښتونه |
| **کارمندان او معاشونه** | د کارکوونکو ریکارډونه او معاش سپارل |
| **ګدام (زخیره)** | د هرې څانګې شتون؛ په پیرود زیات، په پلور کمېږي |
| **فعالیتونه** | د هر بدل بشپده تاریخچه (audit) |

## درې ډوله کسان

> **یادونه:** یو حساب کولای شي په کارونې پورې تړلی بېلګ رولونه واخلي.

1. **سوداګري** — پلورونکی یا د دوکان خاوند
2. **پیرودونکی** — B2B یا B2C پیرود
3. **عرضه‌کوونکی** — ځینې بهرنی ملګی
