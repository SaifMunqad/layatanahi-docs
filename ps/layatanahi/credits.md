# مننه‌لیک

لياتناهی د ډېرو کسانو د هڅې او د خلاص‌سورچه (open-source) ټولنې پر مخ ولاړ دی چې داسې پلیټ‌فارم ممکن کوي.

## ډله

محصول د لياتناهی ډلې لخوا ډیزاین، جوړ، ازمويل او ساتل کېږي. ← بشپړه [ډله](/docs/layatanahi/team) پاڼه وګوره.

## لارښوونه او ملاتړ

> **یادونه:** لومړنۍ پراختیا د **پروفیسر نصیر احمد شینواری** د لارښوونې پر بنسټ وشوه، ترڅنګ یې استادانو، هم‌صنفانو، بهرنیو ازموونکو او پراخې ټولنې چې بیاکتنه او فیډبک یې ورکړ.

## په خلاص‌سورچه جوړ شوی

لياتناهی د هغو خلاص‌سورچه وسیلو له امله ممکن شوی چې پرې ولاړ دی:

| پوړ | ټیکنالوژي |
| --- | --- |
| بیک‌اینډ | `Laravel` |
| د اپ پله | `Inertia.js` |
| فرنټ‌اینډ | `React` + `TypeScript` |
| بڼه | `Tailwind CSS` |
| ډیټابیس | `MySQL` |
| کیش او قطارونه | `Redis` |
| تادیې | `Hesab Pay` |

*مننه* د هرې کتابتون، فریمورک او وسیلې ساتونکو او ونډه‌ګرو ته چې پلیټ‌فارم پرې تکیه لري.

## زموږ پیرودونکو ته

اصلي مننه هغو **سوداګریو او پیرودونکو** ته ځي چې هره ورځ له لياتناهی کار اخلي. ستاسو فیډبک «د معلوماتو انبار» په **ریښتیني سوداګریز پوهاوي** بدلوي. ← زموږ کیسه د [نظریې](/docs/layatanahi/idea) پاڼه ولوله.
