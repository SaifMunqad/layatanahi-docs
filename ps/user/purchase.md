# پیرود

په لیاتناهی کې پیرود یو لنڍ، لارښود شوی جریان دی. د پیرود د بشپړولو دوې لارې شته: له محصول پاڼې څخه **اوس واخله**، یا **سبد ته ورزیات** او وروسته یې تسویه.

## مستقیم پیرود (اوس واخله)

دا د یوې چټکې، یو‌توکۍ غورلړدې لپاره وکاروه.

1. محصول خلاص کړه او **اوس واخله** وټکه.
2. **شمېر** تصدیق کړه او **ټوله بیه** وګوره.
3. د استوه کړنو جزئیات وکتله.
4. پیرود ومنه ترڅو **تسویې** ته ولاړ شه.

## سبد پیرود (سبد ته ورزیات)

دا د څو توکو راټولولو لپاره مخکې له ورکولو وکاروه.

1. په هر وغواړل شوي محصول **سبد ته ورزیات** وټکه.
2. **سبد** خلاص کړه ترڅو شمېرې او بیې وګورې.
3. هره کرښه *زیاته*، *کمې* یا **لرې** کړه، بیا پیرود ته دوام ورکړه یا **تسویې** ته ولاړ شه.

## په تسویه کې څه کېږي

کله چې پیرود ومنه، سیستم توکي تصدیق کوي، **وروستۍ راکړه** (مالیات پکې) محاسبه کوي، معامله په خوندي ډول ثبتوي او ستاسو **غورلړده** د اړیندو اسنادو سره جوړوي.

> **یادونه:** مخکې له منلو، حتماً **د محصول جزئیات** وګوره — بیه، شمېر، مشخصات او شتون — ترڅو غورلړده کټ مټ هغه وي چې ته یې تمه لرې.

## ستاسو بل (پرسند)

وروسته له منلو، یو **بل** جوړېږي او ستاسو ته راļولي کېږي. پکې دا شامل دي:

| توکی | شتون |
| --- | --- |
| د محصول نوم او شمېر | ✅ |
| واحد بیه او ټولګه | ✅ |
| مالیات | ✅ |
| د استوه جزئیات | ✅ |
| د غورلړدې مرجع | ✅ |

بل ستاسو **رسمي رسید** دی او د تصدیق او ساتنې لپاره کارول کېږي.

## تعقیب او ملاتړ

وروسته له پیرود، غورلړده له **تصدیق ← استوه ← رسولو** پورې مخکې ځي. هر ګام یې له حساب خپل تعقیب کړه. که کومه ناسمه ښکاري، کله چې [له ملاتړ سره اړیکه](/docs/support/contact-team) نیسې د بل **د غورلړدې مرجع** وکاروه.

> **سپارښتنه:** خپل **د غورلړدې مرجع** څنګه وساته — ملاتړ ته د ژرې مرستې ترټولو چټکه لاره ده.
