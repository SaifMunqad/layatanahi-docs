# محصولات

`GET /api/v2/products` د سوداګرۍ د محصولاتو کټالوګ راوړي. یو محصول یوازې هغه وخت ښکاري چې لږ تر لږه
یوه هغه څانګه چې اعتبارنامې ته ښکاري، د هغه د یوه ډول لپاره فعاله د ذخیرې کرښه ولري، ترڅو کټالوګ له
هغه څه سره همغږی پاتې شي چې سوداګري په رښتیا یې پلورلی شي.

## صلاحیت

| اړتیا | ارزښت |
| --- | --- |
| وړتیا | `products:read` |
| د پاڼې صلاحیت | `inventory.products.read` |
| د څانګې چلند | د ټولې سوداګرۍ یا په څانګه فلټر شوی |

## د پوښتنې پارامترونه

| پارامتر | ډول | ډیفالټ | یادښتونه |
| --- | --- | --- | --- |
| `search` | string ≤ 100 | — | د محصول کوډ، ماډل یا ژباړل شوي نوم سره سمون خوري |
| `language_code` | string | د اپلیکېشن محل | دوه‌توره کوډ، اختیاري د سیمې سره |
| `page` | integer ≥ 1 | 1 | د پاڼې شمېره |
| `per_page` | integer 1–100 | 25 | د پاڼې کچه |

د محصولاتو لپاره د نېټې فلټر نشته. لټون د `LIKE` سمون دی، نو لنډې کلمې پراخې پایلې راوړي.

## غوښتنه

```bash
curl -s "https://app.example.com/api/v2/products?search=router&language_code=fa_AF" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Accept: application/json"
```

## ځواب

```json
{
  "data": [
    {
      "id": 128,
      "code": "NET-0042",
      "product_model": "AX3000",
      "product_name": "روتر ای‌ایکس ۳۰۰۰"
    }
  ],
  "links": { "first": "...", "last": "...", "prev": null, "next": null },
  "meta": { "current_page": 1, "last_page": 1, "per_page": 25, "total": 1 }
}
```

## فیلډونه

| فیلډ | معنا |
| --- | --- |
| `id` | د محصول پېژندونکی، په ټولو ژبو کې باثباته |
| `code` | د محصول دننی کوډ |
| `product_model` | د جوړونکي ماډل |
| `product_name` | ژباړل شوی نوم، چې د نه‌شتون پر مهال د محصول کوډ ته راګرځي |

د محصول نوم د غوښتل شوې ژبې لپاره ټاکل کېږي. که هیڅ ژباړه شتون ونه لري، API د خالي متن پر ځای د محصول
کوډ راوړي.

## د ژبې مدیریت

1. که `language_code` ورکړل شوی وي، نورمال کېږي (د بېلګې په توګه `fa-AF` په `fa_AF` بدلیږي).
2. که دا نه وي ورکړل شوی، د اپلیکېشن محل کارول کېږي.
3. که ژبه نامعلومه وي، په ډاټابیس کې لومړۍ ژبه کارول کېږي.
4. په یوه ژبه کې، یوه ژباړه په ټاکلي (deterministic) ډول غوره کېږي.

په ادغام کې ژبه ثابته کړئ ترڅو نومونه هغه وخت بدل نه شي کله چې کاروونکی خپله د انټرفېس ژبه بدلوي.

## د ساحې چلند

- د ټولې سوداګرۍ اعتبارنامه: هغه محصولات چې په هرې فعالې څانګې کې ذخیره لري.
- د څانګې ته محدوده اعتبارنامه: یوازې هغه محصولات چې په ورکړل شوو څانګو کې ذخیره لري.
- `X-Business-Branch` پایله هماغه څانګې ته محدوده کوي.

هغه محصول چې ذخیره یې یوازې داسې څانګه کې وي چې تاسو یې نه شي کتلی، نه ښکاري، که څه هم کوډ یې پېژنئ.

## پاڼه‌بندي او ترتیب

محصولات په `id` صعودي ترتیب سره راځي، چې په پاڼو کې باثباته دی. `per_page` تر 100 پورې وکاروئ او د
`next` لینک تعقیب کړئ. وګورئ [پاڼه‌بندي او فلټر](/docs/api/pagination).

## معمول کارونې حالات

| کارونه | لاره |
| --- | --- |
| د کټالوګ همغږي | د ټولو محصولاتو پاڼې وګرځئ، `id` د بهرنۍ کیلې په توګه وساتئ |
| د بارکوډ لټون | په `code` یا ماډل سره لټون وکړئ |
| ژباړل شوی کټالوګ | په ثابت `language_code` غوښتنه وکړئ |
| د شتون کتنه | د مقدارونو لپاره له `/api/v2/stock` سره یوځای کړئ |

## محدودیتونه

- یوازې لوستل: محصولات نه شي جوړېدای یا سمېدای.
- د بیې لګښت او د عرضه‌کوونکو معلومات نه خپرېږي.
- یوازې هغه محصولات ښکاري چې په یوه ښکارېدونکې څانګه کې فعاله ذخیره لري.
- `search` wildcards نه مني؛ دا د فرعي تورو (substring) سمون دی.
