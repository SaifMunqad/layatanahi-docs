# تېروتنې

API د HTTP د حالت معیاري کوډونه او یوه کوچنۍ JSON د تېروتنې لفافه کاروي. د تصدیق هویت او کوټې
ناکامۍ `{"error":{"code":"...","message":"..."}}` راوړي؛ د تفصیل نه‌شتون ریکارډ یوه تړلې بڼه کاروي چې
کیلي یې هم دننه `error` تکراروي.

تل لومړی د HTTP حالت وګورئ، بیا `error.code` ولولئ.

## د تېروتنو لفافې

### معیاري

```json
{
  "error": {
    "code": "api_ability_denied",
    "message": "This credential is not permitted to perform the requested operation."
  }
}
```

### د تفصیل نه‌شتون ریکارډ

```json
{
  "error": {
    "error": "not_found",
    "message": "Sale not found."
  }
}
```

### تصدیق (Validation)

د تصدیق ناکامۍ د چوکاټ بڼه تعقیبوي: یو `message` او یو `errors` څیز چې د ساحو په اساس کیلي‌لاري لري.

```json
{
  "message": "The given data was invalid.",
  "errors": {
    "to": ["The to field must be a date after or equal to from."]
  }
}
```

## د حالت کوډونه

| حالت | معنا | معمول لامل |
| --- | --- | --- |
| 200 | بریالیتوب | — |
| 401 | نه‌تصدیق شوی | ټوکن ورک، بېرته اخیستل شوې اعتبارنامه، د ټوکن ناسم ډول |
| 403 | منع شوی | وړتیا، ګډون یا د څانګې ساحه رد شوې |
| 404 | ونه موندل شو | د تفصیل پېژندونکی په لید وړ ساحه کې نشته |
| 405 | میتود اجازت نلري | GET یا DELETE د MCP ننوتنې ته لېږل شوی |
| 422 | تصدیق ناکام شو | ناسمه نېټه، د پاڼې ناسمه کچه، اړینه څانګه |
| 429 | ډېرې غوښتنې | د فج محدودیت یا د ورځې/میاشتې کوټه |
| 500 | د سرور تېروتنه | غیر منتظره ناکامۍ، د زیاتېدونکي انتظار سره بیا هڅه وکړئ |

## د کوډونو مرجع

| کوډ | حالت | معنا | حل |
| --- | --- | --- | --- |
| `integration_credential_required` | 401 | په غوښتنه کې د ادغام ټوکن نشته | `Authorization: Bearer <token>` ولېږئ |
| `integration_credential_invalid` | 401 | اعتبارنامه بېرته اخیستل شوې، سوداګري غیر فعاله، د کاروونکي توپیر | اعتبارنامه جوړه یا وڅرخوئ |
| `integration_membership_inactive` | 403 | د کارکوونکي ګډون لرې شوی | کاروونکی بیا دندې ته وګومارئ یا بله اعتبارنامه وکاروئ |
| `integration_role_revoked` | 403 | مالک نور مدیر یا د څانګې مدیر نه دی | رول بېرته ورکړئ یا اعتبارنامه بیا صادره کړئ |
| `integration_branch_scope_empty` | 403 | د څانګې ته محدوده اعتبارنامه په ساحه کې څانګه نه لري | یوه مدیریت شوې څانګه ورکړئ یا یې د ټولې سوداګرۍ کړئ |
| `api_ability_denied` | 403 | وړتیا نشته، یا رول نور یې نه ورکوي | وړتیا او د پاڼې صلاحیت ورکړئ |
| `branch_scope_denied` | 403 | څانګه د اعتبارنامې له ساحې بهر ده | یوه ورکړل شوې څانګه وکاروئ |
| `branch_required` | 422 | څو څانګې ورکړل شوې دي او هیڅ نه ده نومول شوې | `X-Business-Branch` ولېږئ |
| `integration_token_not_allowed` | 403 | ټوکن په غیر ادغام لاره کې کارول شوی | یوازې `/api/v2` یا `/mcp` وکاروئ |
| `api_burst_limit_exceeded` | 429 | په یوه دقیقه کې له 60 زیاتې غوښتنې | د `Retry-After` انتظار وکړئ |
| `api_quota_exceeded` | 429 | د ورځې یا میاشتې کوټه پوره شوې | د بیا پیل انتظار وکړئ یا پلان لوړ کړئ |

د MCP په دننه کې د وسیلې کچې ناکامۍ کیدای شي د HTTP تېروتنې پر ځای د تېروتنې پیغام راوړي؛ وګورئ
[د MCP ستونزو حل](/docs/mcp/troubleshooting).

## د نرخ محدودیت تېروتنې

```json
{
  "error": {
    "code": "api_burst_limit_exceeded",
    "message": "Too many API requests in a short period.",
    "retry_after_seconds": 17
  }
}
```

```json
{
  "error": {
    "code": "api_quota_exceeded",
    "message": "The API request quota has been reached.",
    "scope": "user",
    "period": "day",
    "limit": 200,
    "used": 200,
    "reset_at": "2026-11-01T00:00:00+04:30",
    "retry_after_seconds": 18234
  }
}
```

دواړه د ځواب سرلیک `Retry-After` لري. د ثابت ځنډ پر ځای همدغه سرلیک ومنئ.

## د بیا هڅې استراتیژي

| حالت | بیا هڅه؟ | استراتیژي |
| --- | --- | --- |
| 401, 403 | نه | اعتبارنامه یا صلاحیتونه سم کړئ |
| 404 | نه | ریکارډ په ساحه کې نشته |
| 422 | نه | غوښتنه سمه کړئ |
| 429 | هو | د `Retry-After` انتظار، بیا زیاتېدونکی انتظار (backoff) |
| 500 | هو | زیاتېدونکی انتظار، او د هڅو حد وټاکئ |

د اجازې تېروتنه بیا کول یوازې کوټه مصرفوي. هغه لاګ کړئ او خبرتیا ورکړئ.

## د لاګ کولو سپارښتنې

- د ننوتنې نوم، حالت، `error.code` او د غوښتنې پېژندونکی لاګ کړئ که ستاسو پراکسي یې ورکوي.
- بېرر ټوکن یا پټ کوډ هېڅکله مه لاګ کړئ.
- ناکامۍ د ترتیباتو کې د اعتبارنامې د کارونې له کارت سره ونیسئ.
- له یوهې اعتبارنامې څخه تکراري `403` د سرچینې په سیسټم کې د صلاحیتونو کمښت (regression) وګورئ.
