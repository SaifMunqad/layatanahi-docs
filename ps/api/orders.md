# فرمایشونه

`GET /api/v2/orders` هغه فرمایشونه راوړي چې د څانګو ترمنځ دي او سوداګرۍ ته ښکاري. فرمایش هغه سند دی چې د
څانګو ترمنځ د پېرود یا پلور مخکې راځي؛ خپل حالت، د تعقیب نمبر او د بل ټولګې لري.

## صلاحیت

| اړتیا | ارزښت |
| --- | --- |
| وړتیا | `orders:read` |
| د پاڼې صلاحیت | `sale.orders.read` |
| د څانګې چلند | د ټولې سوداګرۍ یا په څانګه فلټر شوی |

## د پوښتنې پارامترونه

| پارامتر | ډول | ډیفالټ | یادښتونه |
| --- | --- | --- | --- |
| `from` | date | — | شامل پیل، د فرمایش د جوړېدو پر بنسټ |
| `to` | date | — | شامل پای؛ باید له `from` سره مساوي یا وروسته وي |
| `status` | enum | — | یو له ملاتړ شوو حالتونو |
| `page` | integer ≥ 1 | 1 | د پاڼې شمېره |
| `per_page` | integer 1–100 | 25 | د پاڼې کچه |

ملاتړ شوي حالتونه: `pending`, `deleted`, `shipped`, `completed`, `approved`, `denied`. هر بل ارزښت
په `422` ردېږي.

## غوښتنه

```bash
curl -s "https://app.example.com/api/v2/orders?status=pending&from=2026-10-01" \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-Business-Branch: 4" \
  -H "Accept: application/json"
```

## ځواب

```json
{
  "data": [
    {
      "id": 88,
      "business_branch_id": 4,
      "order_number": "ORD-2026-0088",
      "tracking_number": "TRK-99120",
      "status": "pending",
      "invoice_number": "INV-2026-7781",
      "grand_total": 18500.0,
      "paid_amount": 0.0,
      "created_at": "2026-10-24 09:02:11"
    }
  ],
  "meta": { "current_page": 1, "last_page": 1, "per_page": 25, "total": 1 }
}
```

## فیلډونه

| فیلډ | معنا |
| --- | --- |
| `id` | د فرمایش پېژندونکی |
| `business_branch_id` | هغه څانګه چې ستاسو لوري ته پروت دی |
| `order_number` | د انسان لپاره د لوستلو وړ د فرمایش مرجع |
| `tracking_number` | د لېږونکي یا دنني تعقیب مرجع، کله چې شتون ولري |
| `status` | اوسنی حالت |
| `invoice_number` | فرمایش ته نښلول شوی بل |
| `grand_total`, `paid_amount` | د بل ټولګې د بل په اسعارو کې |
| `created_at` | د فرمایش د جوړېدو وخت |

ځواب د فرمایش کرښې نه لري. د کرښې کچې تفصیل لپاره ویب انټرفېس یا د پېرود او پلور ننوتنې وکاروئ.

## د حالتونو معناوې

| حالت | معنا |
| --- | --- |
| `pending` | جوړ شوی او د پرېکړې په تمه دی |
| `approved` | منونکې څانګې ومنه یې |
| `shipped` | توکي لېږل شوي |
| `completed` | پوره شوی او تړلی دی |
| `denied` | منونکې څانګې رد کړ |
| `deleted` | نرم‌ډول ړنګ شوی خو فلټر لا هم یې راپور ورکوي |

`deleted` یوازې هغه وخت ښکاري چې په ډاګانه ډول وغوښتل شي. دا هغه فرمایش ښیي چې له فعالې کارونې څخه
لرې شوی دی؛ د پوره‌کولو د حالت په توګه یې مه وګورئ.

## د څانګې سمون

فرمایش هغه وخت راځي چې یو لوری یې په ښکارېدونکې څانګه کې وي:

- بل د یوه ښکارېدونکې څانګې له خوا صادر شوی وي، یا
- بل یوه ښکارېدونکې څانګې ته پته کړی وي.

`business_branch_id` هغه څانګه راپور ورکوي چې ستاسو لوري ته ده. کله چې اعتبارنامه یوه څانګې ته محدوده
وي، یوازې هغه فرمایشونه ښکاري چې هماغه څانګه پکې ښکیل ده.

## ترتیب

فرمایشونه د جوړېدو له مخې له نوې څخه زوړ راځي، چې تدریجي همغږي اسانه کوي: لومړۍ پاڼه وغواړئ او هغه
ځله ودروئ چې داسې فرمایش ته ورسېږئ چې دمخه مو ساتلی وي.

## معمول کارونې حالات

| کارونه | لاره |
| --- | --- |
| د راتلوونکو فرمایشونو قطار | د څانګې لپاره `status=pending` فلټر کړئ |
| د لېږد تعقیب | د `shipped` فرمایشونو لپاره `tracking_number` ولولئ |
| د څانګو ترمنځ پرتله‌کول | د فرمایش ټولګې د نښلول شوي پېرود یا پلور سره پرتله کړئ |
| ورځنی لنډیز | `from` نن ته وټاکئ، په حالت ګروپ کړئ |

## محدودیتونه

- یوازې لوستل: فرمایشونه د API له لارې نه شي جوړېدای، منل کېدای یا ړنګېدای.
- کرښې شاملې نه دي.
- مبالغې د بل په اسعارو کې دي، پرته له تبادلې.
- هغه فرمایشونه چې د لید وړ څانګې له ساحې بهر دي، په بشپړ ډول بهر پاتې کېږي.
