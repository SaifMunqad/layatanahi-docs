# ذخیره

`GET /api/v2/stock` د ذخیرې کرښې راوړي: یو ریکارډ د هرې څانګې په هر ځای کې د هر محصول د هر ډول لپاره.
دا هغه ننوتنه ده چې د شتون، بیا ډکولو او د ګودام د پرتلو (reconciliation) لپاره کارول کېږي.

## صلاحیت

| اړتیا | ارزښت |
| --- | --- |
| وړتیا | `stock:read` |
| د پاڼې صلاحیت | `inventory.branches.read` |
| د څانګې چلند | د ټولې سوداګرۍ یا په څانګه فلټر شوی |

## د پوښتنې پارامترونه

| پارامتر | ډول | ډیفالټ | یادښتونه |
| --- | --- | --- | --- |
| `language_code` | string | د اپلیکېشن محل | د محصول نومونو ژبه |
| `page` | integer ≥ 1 | 1 | د پاڼې شمېره |
| `per_page` | integer 1–100 | 25 | د پاڼې کچه |

په ذخیره کې لټون یا د نېټې فلټر نشته. له `X-Business-Branch` سره یې په څانګه محدوده کړئ، یا راغلې
کرښې د پیرودونکي په اړخ کې فلټر کړئ.

## غوښتنه

```bash
curl -s "https://app.example.com/api/v2/stock?per_page=100" \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-Business-Branch: 4" \
  -H "Accept: application/json"
```

## ځواب

```json
{
  "data": [
    {
      "id": 5512,
      "business_branch_id": 4,
      "product_id": 128,
      "product_code": "NET-0042",
      "product_model": "AX3000",
      "product_name": "Router AX3000",
      "sku": "AX3000-BLK",
      "available_quantity": 12.0,
      "received_quantity": 20.0,
      "reserved_quantity": 8.0,
      "is_available": true,
      "expiry_date": null
    }
  ],
  "meta": { "current_page": 1, "last_page": 1, "per_page": 100, "total": 1 }
}
```

## فیلډونه

| فیلډ | معنا |
| --- | --- |
| `id` | د ذخیرې د کرښې پېژندونکی |
| `business_branch_id` | هغه څانګه چې په فزیکي ډول یې ذخیره لري |
| `product_id`, `product_code`, `product_model` | د محصول پېژندنه |
| `product_name` | ژباړل شوی نوم، چې پر نه‌شتون کوډ ته راګرځي |
| `sku` | د ډول SKU |
| `available_quantity` | هغه مقدار چې اوس یې پلورلای شئ |
| `received_quantity` | هغه مقدار چې ځای ته ترلاسه شوی |
| `reserved_quantity` | هغه مقدار چې خلاصو سندونو ته ژمن شوی |
| `is_available` | چې کرښه د شتون په توګه خپره شوې ده که نه |
| `expiry_date` | د ختمېدو نېټه، کله چې محصول یې ولري |

مقدارونه د عددونو په توګه راځي او کیدای شي اعشاري وي. دا مه فرض کړئ چې صحیح عددونه دي.

## د مقدارونو لوستل

| پوښتنه | د فیلډونو ګډون |
| --- | --- |
| کولای شم 10 واحدونه ژمن کړم؟ | `available_quantity >= 10` |
| ټول یې څومره ترلاسه کړي دي؟ | `received_quantity` |
| ولې شته مقدار له ترلاسه شوي کم دی؟ | `reserved_quantity` توپیر تشریح کوي |
| ایا کرښه خپره شوې ده؟ | `is_available` باید true وي |

شته مقدار هغه شمېره ده چې د پلور بهیر ورته باور کوي. خوندي شوی مقدار دوه ځله نه پلورل کېږي، که څه هم
په فزیکي ډول شتون لري.

## ترتیب او پاڼه‌بندي

کرښې د ذخیرې د `id` صعودي ترتیب سره راځي. د پاڼې ډیفالټ کچه 25 ده او اعظمي یې 100 دی، نو یو بشپړ ګودام
پاڼه‌بندي غواړي.

## معمول کارونې حالات

| کارونه | لاره |
| --- | --- |
| د کمې ذخیرې خبرتیا | ټولې کرښې وګرځئ، `available_quantity` له حد سره پرتله کړئ |
| د ګودام پرتله‌کول | د هرې څانګې لپاره غوښتنه وکړئ او له فزیکي شمېر سره یې پرتله کړئ |
| د ختمېدو څارنه | هغه کرښې فلټر کړئ چې غیر خالي `expiry_date` یې نېټه نن ته نږدې وي |
| د بازارونو همغږي | یوازې هغه کرښې خپرې کړئ چې `is_available` پکې true وي |

## محدودیتونه

- یوازې لوستل: د API له لارې سمون، لېږد یا یوځای کول نشي کېدای.
- ړنګ شوې د ذخیرې کرښې او ړنګ شوي ډولونه بهر پاتې کېږي.
- د هغو څانګو ذخیره چې د اعتبارنامې له ساحې بهر دي، هېڅکله نه راځي.
- د بیې لګښت نه خپرېږي؛ یوازې مقدارونه او پېژندنه شته.
