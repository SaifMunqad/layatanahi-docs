# د MCP افزارونه

سرور پنځه افزارونه وړاندې کوي. هر یو یې د لوستلو له عمل سره سمون لري او د پارامترونو شریکه ټولګه کاروي، نو کلاینت چې یو بللی شي، ټول یې بللی شي.

د افزار نومونه او سکیمونه د `tools/list` له لارې ستنېږي؛ دا پاڼه هماغه سکیمونه تشریح کوي.

## شریک پارامترونه

| پارامتر | ډول | قواعد | موخه |
| --- | --- | --- | --- |
| `id` | integer | ≥ 1 | د یو ریکارډ بشپړ جزئیات اخیستل |
| `branch_id` | integer | ≥ 1 | مخاطبه څانګه |
| `per_page` | integer | 1–100 | د پاڼې کچه |
| `page` | integer | ≥ 1 | د پاڼې شمېره |
| `language_code` | string | `xx` یا `xx-YY` | د توکي د نوم ژبه |

ناسم آرګومانونه له پوښتنې له ترسره کولو مخکې ردېږي. سرور د هماغو قواعدو سره تاییدوي لکه HTTP API، نو له حد بهر `per_page` نه بندېږي (clamp نه کېږي)، بلکې ناکامېږي.

## توکي

**تشریح:** د تصدیق‌شوي کارکوونکي د سوداګرۍ د توکو کاتالوګ پلټل.

| اضافي پارامتر | ډول | قواعد |
| --- | --- | --- |
| `search` | string | تر 100 تورو پورې؛ کوډ، ماډل یا ژباړل شوي سره سمون خوري |

```json
{
  "name": "products",
  "arguments": {
    "search": "router",
    "language_code": "en",
    "per_page": 10
  }
}
```

د پاژ شوي توکو لیست ستنوي چې `id`، `code`، `product_model` او `product_name` لري.

## ذخیره

**تشریح:** د تصدیق‌شوي کارکوونکي د سوداګرۍ د زیرمې کچې لوستل.

| اضافي پارامتر | ډول | قواعد |
| --- | --- | --- |
| — | — | یوازې شریک پارامترونه پلي کېږي |

```json
{
  "name": "stock",
  "arguments": {
    "branch_id": 4,
    "per_page": 50
  }
}
```

د زیرمې کرښې ستنوي چې څانګه، د توکي پېژندنه، SKU، شته، ترلاسه‌شوي، خوندي‌شوي (reserved)، دسترس‌پذوري او د پای ته رسېدو نېټه لري. `branch_id` یا سرلیک وکاروئ؛ د څو څانګو اعتبارنامه له دې دواړو پرته `branch_required` تېروتنه ستنوي.

## پېرودونه

**تشریح:** وروستي پېرودونه د تصدیق‌شوي کارکوونکي د سوداګرۍ او څانګې له مخې لوستل.

| اضافي پارامتر | ډول | قواعد |
| --- | --- | --- |
| `from` | string | `YYYY-MM-DD`، شامل |
| `to` | string | `YYYY-MM-DD`، له `from` سره مساوي یا وروسته |

```json
{
  "name": "purchases",
  "arguments": {
    "from": "2026-10-01",
    "to": "2026-10-31",
    "per_page": 25
  }
}
```

له `id` سره، افزار یو پېرود ستنوي چې انوایس، څانګه، عرضه‌کوونکی، توکي او تادیې لري. له `id` پرته، پاژ شوی لیست ستنوي.

## ارډرونه

**تشریح:** وروستي ارډرونه د تصدیق‌شوي کارکوونکي د سوداګرۍ او څانګې له مخې لوستل.

| اضافي پارامتر | ډول | قواعد |
| --- | --- | --- |
| `from`، `to` | string | `YYYY-MM-DD` |
| `status` | string | `pending`، `deleted`، `shipped`، `completed`، `approved`، `denied` |

```json
{
  "name": "orders",
  "arguments": {
    "status": "pending",
    "branch_id": 4
  }
}
```

ارډرونه ستنوي چې د ارډر شمېره، د تعقیب شمېره، حالت، د انوایس شمېره او ټولګې لري. د کرښو توکي پکې شامل نه دي.

## پلورونه

**تشریح:** وروستي پلورونه د تصدیق‌شوي کارکوونکي د سوداګرۍ او څانګې له مخې لوستل.

| اضافي پارامتر | ډول | قواعد |
| --- | --- | --- |
| `from` | string | `YYYY-MM-DD` |
| `to` | string | `YYYY-MM-DD`، له `from` سره مساوي یا وروسته |

```json
{
  "name": "sales",
  "arguments": {
    "from": "2026-10-01",
    "to": "2026-10-31",
    "branch_id": 4,
    "per_page": 25
  }
}
```

له `id` سره، یو پلور ستنوي چې انوایس، پیرودونکی، توکي او تادیې لري.

## د پایلې بڼه

| بلل | پایله |
| --- | --- |
| لیست | د پاژنې object چې `data`، `links` او `meta` لري |
| جزئیات له `id` | د سند object چې دننه `invoice`، مقابل لوری (counterparty)، `items` او `payments` لري |
| ونه موندل شو | د افزار د تېروتنې متن، د مثال په توګه `Purchase not found.` |
| وړتیا رد شوه | د افزار د تېروتنې متن چې روښانه کوي کارکوونکی ته اجازه نشته |

د افزار پایله د MCP په ځواب کې د متنوې محتوا (text content) په توګه JSON کوډ کېږي. کلاینت باید په بریالیتوب کې یې JSON په توګه پارس کړي.

## د پارامترونو سم ټاکل

- کله چې اعتبارنامه له یوې زیاتې څانګې لري، تل `branch_id` ولېږئ.
- د لنډیز کارونو لپاره `per_page=100` وکاروئ ترڅو د رفت‌وبرګړو (round trips) شمېر کم شي.
- د مودې پوښتنو لپاره `from` او `to` وکاروئ؛ که نه، مرستیال ممکن ټوله تاریخچه لنډه کړي.
- `language_code` ولېږئ کله چې مرستیال باید د توکو نومونه په ټاکلې ژبه نقل کړي.
- جزئیات یوازې د لیست له بللو وروسته له `id` سره واخلئ؛ د جزئیاتو بلل په هر ریکارډ کې ګران وي.

## افزارونه څه نه شي کولای

- د ریکارډونو د جوړولو، تازه‌کولو یا لرې کولو هېڅ افزار نشته.
- د حسابونو، معاشاتو، کارکوونکو یا رولونو هېڅ افزار نشته.
- د ازاد متن د پوښتنې هېڅ ژبه نشته؛ آرګومانونه ټاکلي ډول (typed) لري او تاییدېږي.
- د بلې سوداګرۍ پلټنه شتون نلري.
