# د پلور لیست

د پلورونو پاڼه د ستاسو څانګې د هر صادر شوي بل ثبت دی. دا هغه ځای دی چې پلور ومومئ، وګورئ څه پاتې
دي، تادیه راټوله کړئ، کاپي چاپ کړئ، بېرته راستنونه پیل کړئ یا د سمون وړ سند سم کړئ.

لیست په یوه وخت دېرش کرښې د پای نه ختمېدونکي سکرول سره باروي، چاڼګرې په URL کې ساتي، او یوازې هغه
عملونه ښیي چې اوسنی کاروونکی پر هرې کرښه یې اجازه لري.

## دا پاڼه د څه په اړه ده

- پلور موندل د پیرودونکي، د بل شمېرې، اندازې یا نېټې له مخې.
- په یوه کتنه تادیه شوې او پاتې اندازې لیدل.
- پرته له بل پرانیستلو تادیې راټولول.
- د تحویل شوي پلور لپاره بېرته راستنونه پیلول.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| سرلیک | عنوان، بدلونکي عملونه، چاپ، چاڼګره او لټون |
| جدول | پیرودونکی، د بل شمېره، اندازه، تادیه شوې، پاتې، حالت او نېټه |
| د کرښې عملونه | کتل، بېرته راستنونه، سمون، تادیه ترلاسه کول او ړنګول |
| د سکرول نښه | بله پاڼه په اتوماتیک ډول باروي |

## د ستونونو تشریح

| ستون | مانا |
| --- | --- |
| پیرودونکی | د پیرودونکي نوم، یا د څانګو ترمنځ پلور لپاره ترلاسه کوونکې څانګه |
| د بل شمېره | د سند مرجع |
| اندازه | د بل ټوله ټولګه |
| تادیه شوې | تر دې دمه ترلاسه شوې اندازه |
| پاتې | پاتې بیلانس |
| حالت | اوسنی سوداګریز حالت |
| نېټه | د جوړېدو نېټه ستاسو د تقویم په بڼه |

## څنګه یې کارول

### پلور ومومئ

1. **پلور > پلورونه** پرانیزئ.
2. د پیرودونکي نوم، د بل شمېرې، محصول یا څانګې له مخې ولټوئ.
3. د چاڼګرې پینل سره محدود کړئ: د نېټې دوره، حالتونه، د اندازې دوره او ترتیب.
4. **یوازې پاتې** فعال کړئ ترڅو نه تادیه شوي بلونه پر مخ یوسئ.

### پر یوه کرښه عمل وکړئ

- **کتل** د تادیو، بېرته راستنونو او د حالت کنټرولونو سره د چاپ وړ بل پرانیزي.
- **بېرته راستنونه** هغه وخت ښکاري چې پلور د بېرته راستنېدو وړ وي؛ د هغو توکو لپاره چې لا پوښل
  شوي د بېرته راستنونې بهیر پرانیزي.
- **سمون** هغه وخت ښکاري چې پلور د سمون وړ وي؛ عادي د پلور فورم بیا پرانیزي.
- **تادیه ترلاسه کول** هغه وخت ښکاري چې پاتې پور وي؛ تادیه په څانګیز حساب کې ثبتوي.
- **ړنګول** هغه وخت ښکاري چې پلور د ړنګولو وړ وي. ذخیره بېرته راګرځوي، تادیې بېرته ګرځوي او
  پلور په نرمه توګه ړنګوي.

### چاپ

د چاپ عمل یو پاک بل جوړوي. هغه سندونه چې لا مسوده دي، یا مهر او لاسلیک نه لري، نښه کېږي ترڅو
ترلاسه کوونکی پوه شي چې پایلي نه دي.

## څه شی محدود دي

- لوستل `sale.sales` read غواړي. پر هرې کرښه هر عمل write غواړي.
- لیست د ستاسو څانګې صادر شوو پلورنو په ساحه کې دی. هغه پلورونه چې تاسو پکې ترلاسه کوونکی یاست بلې
  څانګې ته اړه لري او دلته نه لیست کېږي.
- سمون او ړنګول هغه وخت پټېږي چې اړونده نښه لرې شي، حتی د لیکلو واک لرونکو کاروونکو لپاره.
- تادیه ترلاسه کول په بل اسعارو کې فعال څانګیز حساب غواړي؛ د اسعارو ترمنځ تادیې د تبادلې اندازه
  غواړي.
- بېرته راستنونه هېڅکله نشي کولی له هغه مقدار زیاته وي چې لا د بېرته راستنېدو وړ دی.
- قلف شوي سندونه د راپور لپاره ښکاره پاتې کېږي خو نه شي بدلېدای.

## لارښوونې او د ستونزو حل

- **یو پلور ورک دی.** د څانګې ټاکونکی وګورئ؛ د بلې څانګې صادر شوي څانګو ترمنځ پلورونه په هماغه
  څانګه کې ښکاري، نه دلته.
- **تادیه ترلاسه کول بند دي.** بل په بشپړه توګه تادیه شوی، یا د هماغو اسعارو د حسابونو لیست تش دی.
- **سمون ورک شو.** کله چې کاغذي کار بشپړ شو یو همکار پلور قلف کړ.
- **پیرودونکی پر اندازې اعتراض لري.** بل پرانیزئ او تر بېرته راستنونې دمخه د محصول کرښې، تخفیف،
  متفرقه اندازه او تادیې پرتله کړئ.
