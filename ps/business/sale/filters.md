# د پلور چاڼګرې او لټون

د پلور ثبت له هرې معاملې سره لویېږي. د چاڼګرې پینل او د لټون څوکۍ یې هغه لیست ته کموي چې ورته
اړتیا لرئ، او ځکه چې حالت په URL کې دی، کولی شئ یوه دقیقه کتنه نښه یا شریکه کړئ.

چاڼګرې پر سرور ستاسو د څانګې په ساحه کې پلي کېږي. دا پایلې محدودولای شي خو هېڅکله د بلې څانګې
پلور نه ښیي.

## دا پاڼه د څه په اړه ده

- د نېټې، حالت، اندازې او پاتې بیلانس له مخې چاڼول.
- د پیرودونکي، بل، محصول یا څانګې له مخې لټون.
- د پایلو ټولګه ترتیبول.
- د چاڼ شوې کتنې د هغې URL له لارې بیا کارول.

## د چاڼګرې پینل

| چاڼګره | اختیارونه | یادښتونه |
| --- | --- | --- |
| نېټه | نن، دا اونۍ، دا میاشت، دودیزه دوره | د پلور د جوړېدو نېټې پر بنسټ |
| حالت | د سوداګریزو حالتونو هر ډول یوځای کول | څو ټاکنه |
| اندازه | لږ تر لږه او ډېر تر ډېره | د بل ټوله ټولګه کاروي |
| ترتیب | کالم او لوری | د پای نېټو او ټولګو لپاره ګټور |
| یوازې پاتې | فعال یا بند | په بشپړه توګه تادیه شوي بلونه پټوي |

چاڼګرې د AND سره یوځای کېږي. دوه حالتونه «هر یو حالت» مانا لري، خو د نېټې او اندازې دورې لا هم
پر دواړو پلي کېږي.

## څنګه یې کارول

1. **پلور > پلورونه** پرانیزئ.
2. **چاڼګره** وټاکئ او هغه برخې چې اړتیا ورته لرئ فعالې کړئ.
3. پلي کړئ. جدول پر ځای بیا بارېږي او URL تازه کېږي.
4. که پیرودونکی، د بل شمېره یا محصول پېژنئ، د لټون اصطلاح ورزیات کړئ.
5. د کتنې ساتلو یا شریکولو لپاره URL کاپي کړئ.

### د لټون چلند

سرور د پیرودونکي یا څانګې نوم، د بل شمېره، د محصولاتو نومونه، ټولګې، د حالت نښه او نېټه سره سمون
خوري. لټون د چاڼ شوي ټولګې دننه پلي کېږي، نو د یوه پیرودونکي لټون د نېټې په دوره کې یوازې د
هماغه پیرودونکي پلورونه په هماغه موده کې راګرځوي.

### بیا تنظیمول

لټون پاک کړئ او فعالې شوې چاڼګرې برخې بندې کړئ. لیست څانګې اصلي حالت ته بېرته ګرځي: نوي پلورونه،
په هره پاڼه دېرش.

## ګټور ترکیبونه

| هدف | ترکیب |
| --- | --- |
| د پیرودونکي پور تعقیبول | یوازې پاتې، د نېټې له مخې له زړو څخه نویو ته |
| ورځنۍ تصفیه | نېټه نن، ټول حالتونه |
| یوازې لوی بلونه | د اندازې لږ تر لږه حد |
| د څانګو ترمنځ پلور چې د منلو په تمه دي | حالت د تایید په تمه |
| د یوه پیرودونکي تاریخچه | د پیرودونکي نوم ولټوئ، د نېټې دوره ورزیات کړئ |
| د میاشتې پای تفتیش | دودیزه دوره چې میاشت رانغاړي، د بل شمېرې له مخې ترتیب |

## څه شی محدود دي

- چاڼګرې `sale.sales` read غواړي او تل د څانګې ساحې سره یوځای کېږي.
- د اندازې چاڼګرې د هر بل ټوله ټولګه په خپلو اسعارو کې پرتله کوي، نو د ګډو اسعارو لیستونه مستقیم
  پرتله کېدای نه شي؛ د تصفیې لپاره د نېټې او پیرودونکي چاڼګرې وکاروئ.
- لټون یو سرور ته سفر دی؛ ډېر لنډ اصطلاحات پراخې پایلې راګرځوي.
- د چاڼګرو حالت د غونډو ترمنځ نه ساتل کېږي. که کتنه مهمه ده URL وساتئ.
- له دې پاڼې څخه صادرول نشته؛ چاپ یا د دوکان راپورونه وکاروئ.

## لارښوونې او د ستونزو حل

- **لیست نه دی بدل شوی.** تایید کړئ چې «پلي کړئ» مو ډک کړی، نه یوازې برخه مو فعاله کړې.
- **یو پېژندل شوی پلور ورک دی.** د حالت چاڼګره پاکه کړئ؛ ممکن لا د تایید په تمه یا مسوده وي.
- **پایلې ورو دي.** پراخه د نېټې دوره پرته له حالت چاڼګرې ډېرې کرښې لټوي؛ یو حالت ورزیات کړئ.
- **همکار بېلې کرښې ویني.** د هغه څانګه بېله ده. چاڼګرې هېڅکله له څانګو نه تېرېږي.
