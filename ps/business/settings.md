# پروفایل او ترتیبات

د ترتیباتو برخه د ننوتلي شخص پورې اړه لري، نه سوداګرۍ ته. دا د پیرودونکو او کارکوونکو ترمنځ
شریکه ده: هماغه پاڼه ستاسو هویت، امنیت، کلیزه او ژبني غوره توبونه، د یوځای کېدو او وتلو غوښتنې، او هغه API سندونه مدیریت کوي چې د سوداګرۍ ډاټا لوستلو لپاره یې کاروئ.

د **سوداګرۍ** او **څانګې** د ترتیباتو ننوتنې هماغې پروفایل پاڼې ته اشاره کوي. دا یوازې د دې لپاره دي چې مینو د کاري فضا جوړښت ښکاره کړي، خو ستاسو حساب لپاره یو هویت شته.

## دا پاڼه د څه په اړه ده

- ستاسو نوم، انځور، ټیلیفون او ایمېل سم ساتل.
- ټاکل چې نېټې څنګه ښکاره شي او انټرفېس کومه ژبه کاروي.
- هغه غوښتنې کتل چې لېږلې یا ترلاسه کړې مو دي او هغه ارډرونه چې ستاسو حساب ته نښلول شوي دي.
- ستاسو شخصي API سندونه د ټاکلو څانګو لپاره صادرول.

## د پاڼې جوړښت

| ټب | څه شی لري |
| --- | --- |
| عمومي | د حساب جزئیات چې یوازې لوستل کېږي، د تازه کولو عمل سره |
| امنیت | پټنوم، دوه-مرحلې تایید او باوري وسیلې |
| API ادغامونه | د سندونو لیست، د کوټې کارت او د جوړولو/سمون فورمونه |
| محرمیت | د شخصي ډاټا صادرول او د رضایت کنټرولونه |
| ارډرونه | ستاسو حساب ته نښلول شوي ارډرونه د تادیې او لغوه کولو عملونو سره |
| غوښتنې | د یوځای کېدو، وتلو او د دیپارټمنټ بدلون غوښتنې |
| د لېږد معلومات | خوندي شوې د رسولو پتې |
| نور ترتیبات | د کلیزې ډول، بڼه، ژبه او د چټبوټ غوره توبونه |

د هویت کارت په سر کې ستاسو انځور، ښکاره نوم او دندې عنوان ښیي. انځور پورته کول یا لرې کول د هماغه کارت له مخې کېږي.

## څنګه یې کارول

### خپل پروفایل تازه کړئ

1. **ترتیبات** پرانیزئ او **پروفایل تازه کړئ** وټاکئ.
2. خپل لومړی او وروستی نوم، کارن نوم، ایمېل یا ټیلیفون بدل کړئ.
3. خوندي کړئ. د تایید یا بې سارۍ تېروتنه پر اړوندې ساحه ښکاري.

| ساحه | اړین | قواعد |
| --- | --- | --- |
| لومړی نوم | هو | تر 25 تورو پورې |
| وروستی نوم | هو | تر 25 تورو پورې |
| کارن نوم | نه | توري، عددونه، کرښې او لاندې کرښې؛ بې ساری |
| ایمېل | هو | سم او بې ساری |
| ټیلیفون | هو | افغان نړیوال بڼه؛ په پلیټفارم کې بې ساری |

### غوره توبونه بدل کړئ

1. **نور ترتیبات** پرانیزئ.
2. د ښکارېدنې حالت وټاکئ (روښانه، تیاره یا سیسټم).
3. د کلیزې ډول وټاکئ. Shamsi د افغان سوداګرۍ لپاره ډیفالټ دی؛ میلادي، هجري او عربي
   انتخابونه هم شته.
4. د انټرفېس ژبه وټاکئ.
5. خوندي کړئ. بدلون ستاسو په راتلونکي تګ کې پلي کېږي.

### د API ادغامونه مدیریت کړئ

1. **API ادغامونه** پرانیزئ.
2. **جوړول** وټاکئ او سند ته نوم ورکړئ.
3. پریکړه وکړئ چې د ټولې سوداګرۍ دی که ټاکلو څانګو ته محدود. کله چې د ټولې سوداګرۍ نه وي،
   لږ تر لږه یوه څانګه اړینه ده.
4. وړتیاوې وټاکئ: توکي لوستل، ذخیره لوستل، پېرود لوستل، ارډرونه لوستل او پلور لوستل.
5. خوندي کړئ او پټ کوډ سمدلاسه کاپي کړئ. دا یوازې یو ځل ښودل کېږي او بیا هېڅکله نه.
6. **څرخول** وکاروئ ترڅو افشا شوی پټ کوډ بدل کړئ او **بېرته اخیستل** ترڅو سند بند کړئ.

د کوټې کارت پلان، د ورځې او میاشتې حد او اوسنی کارول ښیي.

### غوښتنې او ارډرونه اداره کړئ

- **غوښتنې**: هغه په تمه د یوځای کېدو، وتلو او د دیپارټمنټ بدلون غوښتنې چې ستاسو ته رسېدلې دي
  تایید یا رد کړئ.
- **ارډرونه**: یو پاتې ارډر تادیه کړئ یا یو په تمه ارډر لغوه کړئ. لغوه کول یوازې هغه وخت
  بریالي کېږي چې ارډر لا په تمه وي.

### خپلې ډاټا صادرې کړئ

په محرمیت ټب کې **ډاټا ډاونلوډ** وټاکئ. صادرول په قطار کې اچول کېږي او د Excel کاري کتاب په
بڼه رسي چې ستاسو د حساب معلومات او فعالیت لري.

## څه شی محدود دي

- د پروفایل پای ټکي شخصي دي: سرور تل ننوتلی حساب کاروي او هېڅکله له فورم څخه د کاروونکي
  پېژندونکی نه مني. د بل چا پروفایل نه شي سمولای.
- د `/settings/profile` پاڼه په قصد سره د کارکوونکي وړتیا له دروازې بهر ده، ځکه پیرودونکي یې
  هم کاروي. د **سوداګرۍ** او **څانګې** ننوتنې `settings` لوستنې وړتیا غواړي.
- API ادغامونه کتلو لپاره `settings` لوستل او مدیریت لپاره `settings` لیکل غواړي. یوازې د
  سوداګرۍ مدیران یا د څانګو مدیران یې مدیریت کولی شي، او د څانګې مدیر د ټولې سوداګرۍ سند نه
  شي جوړولای.
- ټیلیفون شمېره او ایمېل پته باید بې ساري وي؛ تکراري ارزښتونه د ساحې تېروتنې سره ردېږي.
- د انځور بدلون یوازې هغه فایلونه مني چې تاسو خپله پورته کړي دي.
- هغه غوښتنه نه شي تاییدولای چې ستاسو ته نه ده رسېدلې یا نوره په تمه نه ده.

## لارښوونې او د ستونزو حل

- **پټ کوډ ورک شو.** سند څرخوئ. پخوانی پټ کوډ سمدلاسه کار بندوي.
- **د سند په فورم کې یوه څانګه نشته.** یوازې هغه څانګې ورکولی شئ چې مدیریت یې کوئ.
- **نېټې لا هم میلادي ښکاري.** غوره توب خوندي کړئ او یو ځل بل ځای ته لاړ شئ؛ پرانیستې پاڼې
  تر بیا بارېدو پورې خپله پخوانۍ بڼه ساتي.
- **د ډاټا صادرول هېڅکله نه رارسي.** کار په قطار کې ځي؛ له یوه مدیر څخه وغواړئ چې د قطار
  کارګر روغتیا تایید کړي.
