# تحلیلونه

تحلیلونه د څانګې د فعالیت ډشبورډ دی. پیسې او حجم په یوه کوچنۍ ټولګه کلیدي شاخصونو، چارټونو
او جدولونو کې یوځای کوي ترڅو مدیر وکولی شي د سوداګرۍ لوری په یوه کتنه وویني: پلور، نغدي بهیر،
پېرود، نوي پیرودونکي او د هر څانګې حساب بیلانس.

له راپورونو سره چې د اسنادو پر بنسټ دي، تحلیلونه د رجحان پر بنسټ دي. دا وکاروئ ترڅو بدلون
وپېژنئ، بیا راپورونه یا فعالیتونه پرانیزئ ترڅو یې تشریح کړئ.

## دا پاڼه د څه په اړه ده

- د ټاکل شوې مودې لپاره اصلي کلیدي شاخصونو لوستل.
- د وخت په اوږدو کې پلور او پېرود پرتلې.
- د خالص نغدي بهیر پوهېدل.
- وتلې تادیې د وېشنو له مخې کتل.
- د څانګې د هر پیسو حساب بیلانس بیا کتنه.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| د کلیدي شاخصونو کارتونه | پلور، راغلي، پېرود، د مودې خالص نغدي بهیر |
| دویمې درجې کارتونه | راغلې تادیې، وتلې تادیې، نوي پیرودونکي، د شتمنیو ټولټال او فعالې شتمنۍ |
| د پلور چارټ | ستونی چارټ د ورځني پلور جدول سره |
| د عوایدو چارټ | د ثبت شوو عوایدو ستونی چارټ |
| د نغدي بهیر چارټ | د خالص نغدي بهیر کرښیز چارټ |
| وتلي لګښتونه د وېشنې له مخې | پیسې چېرې تللې، تفصیل |
| پیسو حسابونه | د حساب نوم، بیلانس او اسعار |

هره شمېره په ټاکل شوو اسعارو کې ښودل کېږي، او کوډ یې د عدد تر څنګ ښکاري.

## د شاخصونو تشریح

| شاخص | معنا |
| --- | --- |
| د پلور ټولټال | په موده کې د صادر شوو بلونو مجموعه |
| د راغلو ټولټال | پر پلور باندې ترلاسه شوې پیسې |
| د پېرود ټولټال | په موده کې د پېرود بلونو مجموعه |
| د عوایدو ټولټال | ثبت شوي غیر پلوري عاید |
| د وتلو ټولټال | په موده کې وتلې پیسې |
| خالص نغدي بهیر | عاید منفي وتلې تادیې |
| نوي پیرودونکي | په موده کې جوړ شوي پیرودونکي، د ټولې سوداګرۍ په کچه |
| د شتمنیو ټولټال او فعالې | د ثبت شوو شتمنیو ارزښت او شمېر |

## څنګه یې کارول

1. **پلورنځی > تحلیلونه** پرانیزئ.
2. اسعار وټاکئ.
3. د کلیدي شاخصونو کارتونه ولولئ. موده په ډیفالټ وروستۍ اووه ورځې ده؛ د یوې ځانګړې بیاکتنې
   لپاره د نېټو حد د URL له لارې ورکول کېدای شي.
4. هغه شاخص ولټوئ چې ناڅاپي بدل شوی.
5. د چارټونو په مرسته تایید کړئ چې بدلون یو ناڅاپي لوړوالی، یو رجحان یا یوه یوازې پېښه ده.
6. د شمېرې شاته اسنادو لپاره راپورونه، یا د انفرادي حرکتونو لپاره فعالیتونه پرانیزئ.

## د چارټونو لوستل

- **پلور** د صادر شوو بلونو ارزښت ښیي؛ له ترلاسه شوو نغدو پیسو سره یو شان نه دی. له راغلو سره یې پرتله کړئ.
- **عواید** یوازې غیر پلوري عاید ښیي، د بېلګې په توګه کرایه یا خدمتونه.
- **خالص نغدي بهیر** عاید منفي وتلې تادیې دی. مثبته کرښه یعنې څانګه په هغه برخه کې له
  تادیې څخه ډېرې پیسې راټولې کړې.
- **وتلي لګښتونه د وېشنې له مخې** ښیي چې ایا یوه لګښتي وېشنه وتونیز بهیر هڅوي.
- **پیسو حسابونه** یو ژوندی بیلانس انځور دی، نه د مودې شمېره.

## څه شی محدود دي

- لوستل `store.analytics` لوستل غواړي. پاڼه هېڅ لیکونکی عمل نه لري.
- ټولې شمېرې د څانګې په کچه دي، د بلونو د صادرولو او ترلاسه کولو څانګې او د تادیو حسابونو له
  مخې. د نویو پیرودونکو شمېر استثنا ده: دا د ټولې سوداګرۍ په کچه دی.
- موده په ډیفالټ اووه ورځې ده؛ پر پاڼه د نېټې ټاکونکی نشته، نو ځانګړی حد باید په URL کې ورکړل شي.
- معلومات په ځنډول شوو ډلو کې بارېږي، نو کارتونه ښايي مخکې له چارټونو ښکاره شي.
- تحلیلونه هېڅکله قانوني راپورونه نه بدلوي؛ دا یوه مدیریتي کتنه ده.
- د بلې څانګې شمېرې هېڅکله نه رانغاړل کېږي، حتی کله چې سوداګري څو موقعیتونه ولري.

## لارښوونې او د ستونزو حل

- **یو شاخص صفر دی خو اسناد شته.** اسعار وګورئ: شمېرې ټاکل شوو اسعارو ته اړول کېږي، او هغه
  اسعار چې فعالیت نه لري صفر ښیي.
- **پلور لوړ دی خو نغدې پیسې کمې دي.** پلور نه تادیه شوي بلونه هم رانغاړي؛ له راغلو او د
  ترلاسه کېدونکو راپور سره یې پرتله کړئ.
- **د حساب بیلانسونه زاړه ښکاري.** دا هغه انځور دی چې د پاڼې سره بار شوی؛ د تادیې وروسته بیا بار کړئ.
- **نوي پیرودونکي ناڅاپي ډېر دي.** هغه شاخص د ټولې سوداګرۍ په کچه دی، نه یوازې ټاکل شوې څانګې ته محدود.
