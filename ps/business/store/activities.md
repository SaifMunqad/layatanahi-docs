# فعالیتونه

فعالیتونه د څانګې یووالي مهال کرښه ده. د دې پر ځای چې هر ماژول پرانیزئ ترڅو پوه شئ څه وشول،
تاسو وروستي پېرودونه، ارډرونه، تادیې، د حسابونو حرکتونه، د زخیرې بدلونونه، پلور او د پلور ارډر
پېښې یو تر څنګ وینئ، هر یو خپل سرچینه سند ته لینک وي.

پاڼه یوازې لوستل کېږي او د «دا چې څوک دا کار وکړ، او کله؟» د ځواب ویلو ترټولو چټکه لار ده.

## دا پاڼه د څه په اړه ده

- په هر ماژول کې د وروستي فعالیت بیا کتنه.
- د یوه بدلون شاته سند موندل.
- تفتیش چې یو عمل چا ترسره کړ.
- کله چې لنډیز بس نه وي، یو ډول فعالیت ته ژوره کتنه.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| د پېرود فعالیتونه | کارکوونکی، بل، حالت، نېټه او عمل |
| د ارډر فعالیتونه | کارکوونکی، بل، حالت، نېټه او عمل |
| د تادیو فعالیتونه | کارکوونکی، څانګه، لوری، سرچینه، مرجع، اندازه، نېټه |
| د حساب فعالیتونه | کارکوونکی، حساب، اندازه، مخکې بیلانس، وروسته بیلانس، نېټه، تشریح |
| د زخیرې فعالیتونه | محصول، تنظیم کوونکی، د عمل شمېر، حالت، نېټه، دلیل |
| د پلور فعالیتونه | کارکوونکی، بل، حالت، نېټه او عمل |
| د پلور ارډر فعالیتونه | کارکوونکی، بل، حالت، نېټه او عمل |

هر جدول وروستي لس کرښې ښیي او د «ټول کتل» لینک وړاندې کوي.

## څنګه یې کارول

### مهال کرښه وګورئ

1. **پلورنځی > فعالیتونه** پرانیزئ.
2. د خپلې پوښتنې لپاره ترټولو اړوندې برخې ته وګورئ: د نغدو پیسو لپاره تادیې، د زخیرې لپاره
   ذخیره، د سوداګرۍ لپاره پلور او پېرود.
3. پر یوه کرښه د عمل لینک وکاروئ ترڅو سرچینه سند پرانیزئ.
4. مخکې له دې چې پایله وګڼئ، د کارکوونکي ستون وګورئ؛ ښايي څو کسان یوه څانګه شریکه کړي.

### یو ډول ته ژوره کتنه

1. پر یوه برخه **ټول کتل** وټاکئ.
2. تفصیلي پاڼه د هغه ډول بشپړ لیست ښیي، دېرش کرښې په یو وخت کې، د لامحدود سکرول سره.
3. منل شوي ډولونه پېرودونه، ارډرونه، پلور، د پلور ارډرونه، تادیې او د حساب فعالیتونه دي.

هر بل ډول «ونه موندل شو» راګرځوي؛ لیست د سیسټم له خوا ټاکل شوی دی.

## د ستونونو تشریح

| د ستون ډله | تفسیر |
| --- | --- |
| کارکوونکی | هغه غونډه چې عمل پکې ترسره شو |
| لوری | پیسې راغلې که ووتلې |
| اندازه او بیلانس | د نښې سره اندازه، د حسابونو لپاره د مخکې او وروسته بیلانس سره |
| حالت | د عمل ډول، د بېلګې په توګه لېږدول شوی، کم شوی یا سم شوی |
| دلیل | هغه تشریح چې د زخیرې کاري بهیر غواړي |
| نېټه | کله چې عمل ثبت شو |

د حساب کرښې ترټولو دقیقې دي: دوی د بیلانس دقیق بدلون ښیي، چې د نغدي صندوق د پرتلې لپاره
ګټورې دي.

## څه شی محدود دي

- لوستل `store.activities` لوستل غواړي. په دې پاڼه باندې هېڅ لیکونکی عمل نشته.
- هر لیست د څانګې په کچه دی: هغه بلونه چې څانګه یې صادروي، پر حسابونو یې تادیې او په ځایونو
  کې یې ذخیره. د بلې څانګې پېښې نه رانغاړل کېږي.
- پاڼه د هرې برخې وروستي لس کرښې ښیي؛ تاریخ لپاره تفصیلي پاڼې وکاروئ.
- د فعالیت مهال کرښه لږ وخت کېش کېږي؛ یو ډېر تازه عمل ښايي لږ وخت ونیسي ترڅو ښکاره شي.
- د سند ړنګول د هغه فعالیت نه پاکوي. د تفتیش ثبت ریکارډونه ښکاره پاتې کېږي.
- د زخیرې برخه له تنظیماتو ریکارډونو څخه اخیستل کېږي؛ دلایل یې تکرار نه کوي.

## لارښوونې او د ستونزو حل

- **یو عمل نشته.** څانګې ټاکونکی وګورئ او د کېش مودې انتظار وکړئ، مخکې له دې چې وګڼئ چې
  ثبت نه شو.
- **کارکوونکی غلط دی.** فعالیتونه هغه غونډه ثبتوي چې عمل پکې ترسره شو، چې ښايي په یوه بوخت
  کاونټر کې ګډ حساب وي.
- **اندازې له راپور سره سمون نه لري.** راپورونه د سند له مخې ډلې کوي؛ فعالیتونه انفرادي حرکتونه
  ښیي، د سمونونو د بېرته راګرځېدو په ګډون.
- **«ټول کتل» ونه موندل شو راګرځوي.** ډول د ملاتړ شوو برخو څخه نه دی.
