# راپورونه

راپورونه د څانګې معاملې مالي صورت حسابونو ته اړوي. ډشبورډ د پلور، پېرود، تادیو، لګښتونو،
ترلاسه کېدونکو او د تادیې وړ په اوږدو کې د مودې لنډه کتنه ورکوي، او هره شمېره هغه تفصیلي
لیست ته لینک ده چې چاپ یا پرتله یې شئ.

راپورونه یوازې لوستل کېږي. دوی هېڅکله سند نه بدلوي، نو د تفتیش پر مهال یې خلاصول بې خطره دي.

## دا پاڼه د څه په اړه ده

- د یوې مودې په اوږدو کې پلور، پېرود او لګښتونه پرتلې.
- په یوه کتنه کې ترلاسه کېدونکو او د تادیې وړ کتل.
- د ورځې، اونۍ، میاشتې، کال یا ټول تاریخ لپاره خالصه ګټه محاسبه کول.
- د هر ټولټال شاته بلونو یا تادیو ته ژوره کتنه.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| چاڼګرې | د مهال کرښې او اسعارو ټاکونکي |
| ټولټالونه | پلور، راغلي، پېرود، د عوایدو تادیې، وتلې تادیې، لګښتونه، ترلاسه کېدونکي، د تادیې وړ، خالصه ګټه |
| اوسطونه | د مودې اوسط ارزښتونه او د ارډرونو شمېر |
| مهال کرښه | د هرې مودې لپاره یوه کرښه د هرې شمېرې سره |
| وروستي لیستونه | وروستي بلونه، تادیې، ترلاسه کېدونکي او د تادیې وړ |

هر ټولټال خپلې تفصیلي پاڼې ته لینک دی چې اوسنۍ مهال کرښه، اسعار او موده یې له ځان سره وړي.

## مهال کرښې

| مهال کرښه | مودې |
| --- | --- |
| ورځ | څلورویشت ساعتي برخې |
| اونۍ | اووه ورځني برخې (ډیفالټ) |
| میاشت | څلور اونیزې برخې |
| کال | دولس میاشتني برخې |
| ټول وخت | د هر تقویمي کال لپاره یوه برخه |

د مودې چیپ ښیي چې کومه برخه ګورئ، د بېلګې په توګه «نن»، «پرون» یا «3 ورځې مخکې».

## تفصیلي پاڼې

| راپور | ستونونه |
| --- | --- |
| پلور | بل، پیرودونکی، اداره، ټول، تادیه شوی، پاتې، نېټه |
| راغلي | بل، ټول، تادیه شوی، پاتې، نېټه |
| پېرود | بل، عرضه کوونکی، ټول، تادیه شوی، پاتې، نېټه |
| د عوایدو تادیې | وېشنې، ډیبټ حساب، کریډیټ حساب، اندازه، نېټه |
| وتلې تادیې | وېشنې، ډیبټ حساب، کریډیټ حساب، اندازه، نېټه |
| لګښتونه | وېشنې، یادښتونه، ثبت کوونکی، اندازه، نېټه |
| خالصه ګټه | د ثبت ډول، مرجع، تفصیل، اندازه، نېټه |
| ترلاسه کېدونکي | بل، پیرودونکی، اداره، ټول، تادیه شوی، پاتې، نېټه |
| د تادیې وړ | بل، عرضه کوونکی، ټول، تادیه شوی، پاتې، نېټه |

هره تفصیلي پاڼه پنځلس کرښې په پاڼو وېشي او د سکرول کولو پر مهال نورې کرښې باروي. اسعار
بدلول مهال کرښه او موده ساتي.

## څنګه یې کارول

1. **پلورنځی > راپورونه** پرانیزئ.
2. مهال کرښه او اسعار وټاکئ.
3. لومړی د ټولټالونو جدول ولولئ؛ دا د مودې بڼه ښیي.
4. پر یوه ټولټال کلیک وکړئ ترڅو تفصیلي لیست یې پرانیزئ.
5. په تفصیلي پاڼه کې د اسعارو ټاکونکی وکاروئ ترڅو هماغه موده په بل اسعارو کې پرتله کړئ.
6. کله چې کاغذي کاپي ته اړتیا وي، تفصیلي پاڼه چاپ کړئ.

## څه شی محدود دي

- لوستل `store.reports` لوستل غواړي. سپریډشیټ اپلوډول یا صادرول لیکل غواړي.
- ټولې شمېرې د څانګې په کچه دي: هغه بلونه چې څانګه یې صادروي یا ترلاسه کوي، او پر څانګې
  حسابونو تادیې. د بلې څانګې فعالیت نه رانغاړل کېږي.
- د نویو پیرودونکو شمېر، چېرې چې ښودل کېږي، د ټولې سوداګرۍ دی نه د یوې څانګې.
- پایلې د چټکتیا لپاره کېش کېږي. یو سند چې څو ثانیې مخکې جوړ شوی، ښايي لږ وخت ونیسي ترڅو ښکاره شي.
- ترلاسه کېدونکي او د تادیې وړ مهال کرښه نه لري؛ دوی اوسنی پاتې حالت ښیي.
- راپورونه هېڅکله د کرښې لګښت یا حاشیه نه ښکاره کوي، پرته له هغه چې د خالصې ګټې کتنه له
  اسنادو څخه اخلي.

## لارښوونې او د ستونزو حل

- **یو ټولټال زوړ ښکاري.** پایلې لږ وخت کېش کېږي. یوه دقیقه انتظار وکړئ او بیا بار کړئ.
- **د مودې چیپ ناڅاپي دی.** مهال کرښه برخې ټاکي؛ اونیزه مهال کرښه له اوسنۍ اونۍ پیلېږي، نه
  له یوې خپل سري نېټې.
- **د اسعارو ټولې له حساب سره توپیر لري.** راپورونه ذخیره شوو تبادلې نرخونو له مخې ټاکل شوو
  اسعارو ته اړوي؛ د حساب دفتر اصلي اندازې ښیي.
- **خالصه ګټه منفي ده.** پېرود او لګښتونه په هغه برخه کې له پلور او عاید څخه ډېر وو. مخکې له
  دې چې پایله غلطه وګڼئ، تفصیلي لیست پرانیزئ.
