# د تنظیماتو تاریخچه

تنظیمات د ذخیرې د تفتیش ثبت دي. هر ځل چې مقدار بدل شي، بیه تازه شي یا دوه کرښې یوځای شي، سیسټم
یوه ننوتنه لیکي: چا یې وکړل، څه بدل شول، پخواني او نوي ارزښتونه، او ولې. دا پاڼه هغه ځای دی چې
دا ثبت پکې لولئ.

کله چې فزیکي شمېر له سیسټم سره سمون ونه لري، دا لومړنی سکرین دی چې باید پرانیستل شي. دا
معمولاً توپیر پرته له اټکل تشریح کوي.

## دا پاڼه د څه په اړه ده

- د څانګې هر ذخیرې حرکت په تاریخي ترتیب کې کتل.
- د یوه بدلون شاته کارکوونکی او دلیل پېژندل.
- له یوې ننوتنې څخه اغېزمن محصول یا اصلي سند ته تګ.
- یو محصول، SKU یا د عمل ډول ته چاڼ کول.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| سرلیک | عنوان، چاپ، لټون او د تنظیماتو د ورزیاتولو عمل |
| جدول | محصول، چا تنظیم کړ، د عمل شمېر، حالت او تاریخ |
| دلیل | ژباړل شوې تشریح، د بېلګې په توګه «په لاره کې زیانمن شوی» |
| د سکرول نښه | زاړه ننوتنې په اتوماتیک ډول باروي |

کرښې د محصول او عمل له مخې ډلبندي شوې دي، نو یو ډله ییز بدلون یو ځل له شمېر سره ښکاري، نه
لږوونکي نږدې یو شان کرښې.

## د عمل ډولونه

| عمل | مانا |
| --- | --- |
| ورزیات شو | مقدار زیات شو |
| کم شو | مقدار کم شو |
| ولېږدېد | مقدار بل ځای ته ولېږدېد |
| یوځای شو | دوه یا زیاتې کرښې یوځای شوې |
| سم شو | بیه، اسعار، ښکارېدنه یا بل مشخص بدل شو |
| ړنګ شو | کرښه له فعالې ذخیرې لرې شوه |

## څنګه یې کارول

### توپیر وڅېړئ

1. **ذخیره > تنظیمات** پرانیزئ.
2. د محصول نوم، ماډل، SKU یا دلیل له مخې ولټوئ.
3. تر هغه دورې چې ګورئ بېرته ترتیب یا سکرول کړئ.
4. ننوتنه پرانیزئ ترڅو کارکوونکی، تاریخ، پخوانی مقدار او نوی مقدار وګورئ.
5. محصول کرښې یا هغه پېرود، پلور یا لېږد ته چې بدلون یې رامنځته کړ لینک تعقیب کړئ.

### له ذخیرې تاریخچې څخه ژور لینکونه

د څانګې یا ګودام د تاریخچې ټب دلته د مخکې ټاکل شوي محصول چاڼګرې سره لینک کوي. سمه کرښه
روښانه کېږي ترڅو پرته له بیا لټون حرکت تایید کړئ.

### لاسي ننوتنه ورزیات کړئ

د ورزیاتولو عمل د write لاسرسي لرونکو کاروونکو ته شته. دا هغه سمون لپاره د تنظیماتو ننوتنه
جوړوي چې نور سند نه لري، د بېلګې په توګه لومړنی شمېر. دا لږ وکاروئ: پېرود، پلور یا لېږد تل له
لاسي یادښت څخه ښه تشریح دی.

## ننوتنه په سمه توګه لوستل

| ساحه | څنګه یې ولولئ |
| --- | --- |
| چا تنظیم کړ | هغه کارکوونکی چې د هغه غونډې بدلون وکړ |
| د عمل شمېر | عمل څو واحدونه یا کرښې اغېزمنې کړې |
| حالت | د عمل ډول، له رنګ او نښې سره ښودل شوی |
| تاریخ | بدلون کله پلی شو، ستاسو د تقویم په بڼه |
| دلیل | هغه اړینه تشریح چې کارکوونکي ولیکله |

یوه ننوتنه تشریح کوي چې *سیسټم څه ثبت کړل*، نه دا چې فزیکي ذخیره ولې توپیر لري. د بېلګې په
توګه، د پلور کموالی یو سم حرکت دی؛ غلا له دلیل سره لاسي کموالی دی.

## څه شی محدود دي

- لوستل `inventory.configuration` read غواړي؛ لاسي ننوتنه ورزیاتول write غواړي.
- ننوتنې د څانګې ساحې لري. د بلې څانګې د ذخیرې لپاره لیکل شوې تنظیمات نه ښکاري.
- لاسي ننوتنه پخپله مقدار نه شي بدلولی؛ دا د بل ځای کې شوي سمون تشریح ثبتوي.
- ننوتنې نه سمېدای شي او نه ړنګېدای شي. د تفتیش ثبت یوازې ورزیاتېدونکی دی، او همدا یې باوري
  کوي.
- پاڼه هېڅکله د لګښت بیې یا د عرضه کوونکي مالي ډاټا نه ښیي.

## لارښوونې او د ستونزو حل

- **هغه ننوتنه چې مې ورته اړتیا لرله ورکه ده.** د څانګې ټاکونکی وګورئ او د تاریخ دوره پراخه
  کړئ؛ ننوتنې پاڼه بندي شوې دي او زاړه کرښې د سکرول کولو سره بارېږي.
- **دلیل ژباړل شوی نه دی.** ځانګړي دلیلونه هماغسې ښکاري چې ولیکل شول؛ یوازې معیاري دلیلونه
  ژباړې لري.
- **د عمل شمېر ډېر لوړ ښکاري.** یو ډله ییز عمل (یوځای کول یا ډله ییز سمون) یوه ننوتنه د ټول
  شمېر سره ثبتوي.
- **یو همکار بدلون ردوي.** ننوتنه هغه کارکوونکې غونډه ثبتوي چې عمل یې کړی؛ د پلورنځي فعالیتونه
  پاڼه پراخه زمینه ښیي.
