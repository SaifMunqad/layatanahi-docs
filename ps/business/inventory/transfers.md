# د ذخیرې لېږد

لېږد د یوې د ذخیرې کرښې مقدار له یوه ځای څخه بل ته وړي پرته له دې چې څه وپېري یا وپلوري. دا
سمه وسیله ده کله چې یو پلورنځی کمښت ولري، کله چې مرکزي ګودام یوه څانګه تمویلوي، یا کله چې
توکي ناسم ځای کې ساتل شوي وي.

Layatanahi جلا د لېږد پاڼه نه لري. لېږدونه د محصول د ذخیرې کتنې څخه ترسره کېږي، او هر لېږد د
تنظیماتو ننوتنه ثبتېږي او په ذخیرې تاریخچه کې ښکاري.

## دا پاڼه د څه په اړه ده

- د ګودامونو او څانګو ترمنځ مقدار لېږدول.
- د ټول مقدار ثابت ساتل پداسې حال کې چې ځایونه بدلېږي.
- ثبتول چې چا څه، چېرې او ولې ولېږدول.
- ترلاسه کوونکي ځای ته خبرتیا ورکول.

## لېږد څنګه کار کوي

| ګام | څه شي پېښېږي |
| --- | --- |
| مقدار ټاکل | ولیکئ چې څو واحدونه لېږدول غواړئ |
| موخه ټاکل | هغه ذخیره یا څانګه ټاکئ چې ورته لاسرسی لرئ |
| تایید | مقدار نشي کولی له شته مقدار زیات وي |
| دلیل ثبتول | دلیل اړین دی |
| پلي کول | سرچینه کموي او موخه زیاتېږي، یا کرښه بل ځای ته ځي |
| خبرتیا | ترلاسه کوونکی ځای خبرتیا ترلاسه کوي |

**بشپړ لېږد** د ذخیرې کرښه بل ځای ته وړي او هویت او بیه یې ساتي. **جزوي لېږد** په موخه ځای
کې کرښه جوړوي یا زیاتوي او پاتې برخه پر ځای پرېږدي.

## څنګه یې کارول

1. **ذخیره > محصولات** پرانیزئ او کرښه ومومئ.
2. د محصول د ذخیرې کتنه پرانیزئ.
3. **د ذخیرې لېږد** وټاکئ.
4. موخه ذخیره یا څانګه وټاکئ. یوازې هغه ځایونه ښکاري چې ستاسو څانګې ته ورکړل شوي.
5. د لېږد مقدار ولیکئ. اعظمي حد شته مقدار دی.
6. دلیل ولیکئ، د بېلګې په توګه «اونیز ډکول» یا «ناسمه الماري».
7. تایید کړئ.

د تنظیماتو ثبت یوه د حرکت ننوتنه لیکي او د دواړو ځایونو د ذخیرې تاریخچه حرکت ښیي.

## لېږد په مقابل کې سمون

| حالت | کوم یې وکاروئ |
| --- | --- |
| توکي په فزیکي ډول بل ګودام ته ولېږدېدل | لېږد |
| توکي زیانمن، ورک یا ناسم شمېرل شوي | سمون یا کموالی |
| توکي پیرودونکي ته وپلورل شول | پلور |
| توکي پیرودونکي بېرته راوګرځول | د پلور بېرته راستنونه |
| په یوه ځای کې تکراري کرښې | یوځای کول |

د زیان لپاره لېږد، یا د ځای بدلون لپاره سمون، د ځای تاریخچه ماتوي او وروسته تفتیشونه ستونزمن
جوړوي.

## څه شی محدود دي

- لوستل `inventory.products` read غواړي؛ لېږد ترسره کول write غواړي.
- سرچینه کرښه باید ستاسو څانګې ته اړه وي. موخه باید هغه ذخیره وي چې ستاسو څانګه ورته لاسرسی
  لري؛ د خپلې خوښې د ذخیرې پېژندونکي ردېږي.
- مقدار باید لږ تر لږه یو وي او د لېږد پر مهال له شته مقدار زیات نه وي.
- دلیل اړین دی او تفتیش کوونکو ته ښودل کېږي.
- لېږدونه هېڅکله د ټولې سوداګرۍ ټول مقدار نه بدلوي؛ یوازې هغه ځای بدلوي چې مقدار پکې دی.
- لېږد نه شي کولی رزرو شوی مقدار ولېږدوي. د یوه ځای له ذخیرې وعدې دمخه پرانیستې غوښتنې
  وګورئ.

## عملي حالتونه

| حالت | سپارښتل شوې لار |
| --- | --- |
| اصلي ګودام یو پلورنځی ډکوي | د ډکولو مقدار جزوي لېږد |
| یو پلورنځی بندېږي او ذخیره یې ځي | د هرې کرښې بشپړ لېږد پاتې ځای ته |
| توکي ناسم ګودام کې ترلاسه شول | سم ګودام ته لېږد، د پېرود سند په مرجع توګه |
| ذخیره باید له بلې څانګې وپلورل شي | لومړی لېږد، بیا له ترلاسه کوونکي ځای څخه پلور |

## لارښوونې او د ستونزو حل

- **موخه ورکه ده.** ستاسو څانګه هغې ذخیرې ته ورکړه نه لري. له یوه مدیر څخه وغواړئ چې له
  ذخیره > څانګې څخه یې ورزیات کړي.
- **مقدار ردېږي.** دا له شته مقدار زیات دی؛ پاڼه تازه کړئ ترڅو اوسنۍ شمېره ترلاسه کړئ.
- **ذخیره په ټولیز ډول کمه شوه.** لېږد باید ټول مقدار نه بدلوي. وګورئ چې ایا پر ځای یې سمون یا
  یوځای کول ترسره شول.
- **ترلاسه کوونکې څانګه ذخیره نه شي لیدلای.** موخه ذخیرې ته لاسرسی له لېږد څخه جلا دی؛ که
  ترلاسه کوونکې څانګه باید ترې وپلوري، لاسرسی ورکړئ.
