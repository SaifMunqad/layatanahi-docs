# د ذخیرې لیست

د ذخیرې محصولاتو پاڼه د هغه هر څه کتلاګ دی چې ستاسو څانګه یې همدا اوس لري. تاسو یې کولای شئ
د کارتونو یا جدول په بڼه وګورئ، یو ډول ولټوئ، بیه او مقدار یې وګورئ، او د ذخیرې کرښه پرانیزئ
ترڅو یې سمون، لېږد یا پلور وکړئ.

دا هغه سکرین دی چې ډېرې عملیاتي پوښتنې ترې پیلېږي: «دا ماډل لرو؟»، «نن یې بیه څومره ده؟»،
«چېرې ساتل کېږي؟».

## دا پاڼه د څه په اړه ده

- د څانګې ذخیره د محصول، ماډل یا SKU له مخې کتل.
- په یوه کتنه بیه، شته مقدار او ځای لیدل.
- د سمون لپاره د ذخیرې کرښه پرانیستل.
- د لیدیز کارتونو شبکې او منظم جدول ترمنځ بدلون.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| سرلیک | عنوان، د کتنې حالت بدلونکی، چاپ او لټون |
| د کارتونو شبکه | د محصول انځور، نوم، ماډل، SKU، بیه، مقدار او اسعار |
| جدول | محصول، ماډل، SKU، بیه، شته مقدار، اسعار او ځای |
| د کرښې عملونه | د تنظیماتو سمون او ذخیرې کموالی |
| د سکرول نښه | بله پاڼه په اتوماتیک ډول باروي |

ټاکل شوی د کتنې حالت په URL کې ساتل کېږي، نو یو شریک شوی لینک هماغه ترتیب پرانیزي.

## د ستونونو تشریح

| ستون | مانا |
| --- | --- |
| محصول | د ډول نوم |
| ماډل | د جوړونکي ماډل مرجع |
| SKU | د ذخیرې ساتلو واحد، د هر ډول لپاره ځانګړی |
| بیه | د پلور بیه، کله چې تخفیف فعال وي د ضمیمې سره |
| شته | هغه مقدار چې همدا اوس یې پلورلای شئ |
| اسعار | د بیې اسعار |
| ځای | هغه ذخیره یا څانګه چې کرښه ساتي |

## څنګه یې کارول

### محصول ومومئ

1. **ذخیره > محصولات** پرانیزئ.
2. د محصول نوم، ماډل یا SKU ولیکئ او ولېږئ. لټون پر سرور ترسره کېږي او لومړي مخ ته بېرته ګرځي.
3. کله چې څو کرښې پرتله کوئ، جدول کتنې ته واوړئ.
4. د کاغذي ذخیرې لیست لپاره د چاپ عمل وکاروئ.

### د ذخیرې کرښه بدله کړئ

1. پر یوه کرښه د سمون عمل وټاکئ.
2. د واحد بیه، اختیاري اسعار، ښکارېدنه یا د لېږد موخه بدله کړئ.
3. د بدلون دلیل ورکړئ.
4. وسپارئ. د تنظیماتو تاریخچه پخواني او نوي ارزښتونه ثبتوي.

### ذخیره کمه کړئ

1. د کموالي عمل وټاکئ.
2. هغه مقدار ولیکئ چې لرې کول غواړئ. دا نشي کولی له شته مقدار زیات وي.
3. دلیل ولیکئ، لکه زیان، د مودې پای یا د شمېرل سمون.
4. تایید کړئ. شته مقدار کموي او د تنظیماتو ثبت ته ننوتنه لیکل کېږي.

## کتل په مقابل کې بدلول

لیست کتل خوندي دي: تر هغه چې عمل پرانیزئ هېڅ شی نه بدلېږي. دوه چلندونه د یادولو وړ دي:

- **د بیې سمون یو د ذخیرې عمل دی.** دلته د بیې بدلون د ذخیرې کرښې ته اغېزه کوي، نه د محصول
  تعریف ته، او له دلیل سره ثبتېږي.
- **ځای د کرښې برخه ده.** دوه یو شان محصولات چې په دوو ګودامونو کې ساتل کېږي د دوو کرښو په توګه
  ښکاري؛ د دوی ترمنځ مقدار لېږدول لېږد دی، نه سمون.

## څه شی محدود دي

- لوستل `inventory.products` read غواړي؛ سمون، کموالی، لېږد، د بیې بدلون او پلور write غواړي.
- یوازې هغه د ذخیرې کرښې راګرځي چې په هغو ذخیرو کې دي چې ستاسو څانګه ورته لاسرسی لري. هغه
  څانګه چې ورکړه نه لري تش لیست ویني، نه د بل ګودام ذخیره.
- د مقدار ساحه په لیست کې یوازې لوستل کېږي؛ دا یوازې د پېرود، پلور، بېرته راستنونې، لېږد، سمون
  یا یوځای کولو له لارې بدلېږي.
- کموالی نشي کولی له شته مقدار زیات وي، او دلیل اړین دی.
- په نرمه توګه ړنګ شوې د ذخیرې کرښې له لیست څخه ورکېږي خو د تفتیش لپاره شته پاتې کېږي.
- لیست هېڅکله د لګښت بیې نه ښیي؛ هغه د پېرود په سندونو کې دي.

## لارښوونې او د ستونزو حل

- **لیست تش دی.** ستاسو څانګه د ذخیرې ورکړه نه لري، یا هرې کرښې لټون چاڼ کړې ده. له یوه مدیر
  څخه وغواړئ چې له ذخیره > څانګې څخه لاسرسی ورکړي.
- **ښودل شوې بیه هغه نه ده چې په تادیه کې کارول کېږي.** د پلور سکرین د پلورونکي ځای د ذخیرې
  کرښه لولي. کله چې تکرارې کرښې شته، تایید کړئ چې سمه کرښه ګورئ.
- **مقدار له فزیکي شمېر څخه کم دی.** تنظیمات پرانیزئ او د سمون دمخه وروستي کموالي، پلور یا لېږد
  ولټوئ.
- **یو محصول دوه کرښې لري.** د مقدارونو په لاسي سمون پر ځای ذخیرې یوځای کول وکاروئ.
