# ذخیرې یوځای کول

تکراري د ذخیرې کرښې معمول دي: هماغه ډول له دوو پېرودونو راځي، د ګودامونو ترمنځ لېږدول کېږي،
یا د یوه سمون پر مهال دوه ځله جوړېږي. ذخیرې یوځای کول هغه کرښې په یوه کې یوځای کوي پرته له دې
چې ټول مقدار یا د تفتیش تاریخچه له لاسه ورکړي.

یوځای کول له لاسي مقدار سمون څخه ډېر خوندي دی. سیسټم مقدارونه جمع کوي، یوه کرښه ساتي او نورې د
یوځای کولو د ثبت شوې ننوتنې سره له کار څخه باسي.

## دا پاڼه د څه په اړه ده

- هغه ډولونه موندل چې له یوې زیاتې د ذخیرې کرښې لري.
- د یوځای کولو لپاره کرښې ټاکل.
- ټاکل چې یوځای شوې ذخیره چېرې او په کومه بیه اوسي.
- د یوځای کولو لپاره دلیل ثبتول.

## د پاڼې جوړښت

| برخه | څه شی ښیي |
| --- | --- |
| لټون | د ډول ماډل، SKU یا د محصول پېژندونکي |
| د ډولونو ډلې | یوازې هغه ډولونه چې له یوې زیاتې د ذخیرې کرښې لري |
| د ذخیرې پینل | د ټاکل شوي ډول کرښې له ټیک بکسونو او ځایونو سره |
| د یوځای کولو فورم | موخه ځای، د یوځای کولو بیه او دلیل |
| د یوځای کولو عمل | یوازې هغه وخت فعالېږي چې لږ تر لږه دوه کرښې ټاکل شوې وي |

## څنګه یې کارول

1. **ذخیره > تنظیمات > ذخیرې یوځای کول** پرانیزئ.
2. ډول ولټوئ، یا یې له ډلو لیست څخه وټاکئ.
3. لږ تر لږه دوه کرښې وټاکئ. کله چې ټول ډول باید یوځای شي، «ټول وټاکئ» وکاروئ.
4. موخه ځای وټاکئ. تش یې پرېږدئ ترڅو یوځای شوې کرښه په خپله څانګه کې پاتې شي.
5. د یوځای کولو بیه ولیکئ. دا د پایله کرښې بیه کېږي.
6. دلیل ورکړئ.
7. یوځای کول تایید کړئ.

### د یوځای کولو پر مهال څه پېښېږي

| اړخ | پایله |
| --- | --- |
| مقدارونه | شته، ترلاسه شوي او رزرو شوي جمع کېږي |
| ځای | یوځای شوې کرښه په ټاکل شوې موخه کې اوسي |
| بیه | هغه بیه چې ولیکله شوه پلي کېږي |
| اسعار | د کرښو ترمنځ تر ټولو عام اسعار ساتل کېږي |
| د پای نیټه | تر ټولو نږدې د پای نیټه ساتل کېږي |
| سرچینه کرښې | صفرېږي او په نرمه توګه ړنګېږي |
| تفتیش | د یوځای کولو تنظیمات ننوتنه سرچینې نوې کرښې ته نښلوي |

## سمه موخه ټاکل

- په هغه ګودام کې یوځای کړئ چې توکي په فزیکي ډول پکې دي. که په دوو ځایونو کې وي، لومړی یوه
  ډله ولېږدئ او بیا یوځای کړئ.
- د بېلابېلو بیو سره کرښې مه یوځای کوئ، پرته له دې چې ټوله ډله بیا بیه کول غواړئ.
- که کرښې بېلابېل اسعار کاروي، د یوځای کولو دمخه تایید کړئ چې کوم اسعار تر ټولو عام دي؛ پایله
  هماغه ساتي.

## څه شی محدود دي

- لوستل `inventory.configuration` read غواړي؛ یوځای کول write غواړي.
- لږ تر لږه دوه کرښې باید ټاکل شوې وي، او ټولې باید د یوه محصول ډول وي.
- هره ټاکل شوې کرښه باید ستاسو څانګې ساحې دننه وي؛ بهرنۍ کرښه ردېږي.
- موخه ذخیره باید هغه وي چې ستاسو څانګه ورته لاسرسی لري.
- دلیل په اعتبار کتنه کې اختیاري دی خو په کلکه سپارښتل کېږي، ځکه د یوځای کولو ننوتنه هغه څه ده
  چې راتلونکي تفتیش کوونکي به یې لولي.
- یوځای کول بېرته نه ګرځېدونکي دي. سرچینه کرښې په نرمه توګه ړنګېږي او له دې سکرین څخه بېرته
  نه شي ووېشل کېدای.

## لارښوونې او د ستونزو حل

- **یو ډول په ډلو لیست کې نه ښکاري.** یوازې یوه کرښه لري، نو د یوځای کولو لپاره څه نشته.
- **د یوځای کولو عمل بند دی.** له دوو څخه کمې کرښې ټاکل شوې دي، یا ټاکنه بېلابېل ډولونه لري.
- **له یوځای کولو وروسته مقدار ناسم ښکاري.** یوې کرښې رزرو شوی مقدار درلود. رزرو شوي واحدونه
  په مجموعه کې شامل دي؛ د یوځای کولو دمخه پرانیستې غوښتنې وګورئ.
- **ناسمې کرښې مو یوځای کړې.** بېرته ګرځېدنه نشته. څرګند دلیل سره پېرود یا سمون ثبت کړئ ترڅو
  ټاکل شوي مقدارونه بېرته راوګرځوئ، بیا اغېزمن سندونه قلف کړئ.
